確率変数・期待値・分散・二項分布の基礎〜応用

1. 確率変数と確率分布

基本概念

試行の結果によってとる値が決まる変数を確率変数 $X$ と呼ぶ。

  • 確率分布： $X$ のとる値 $x_i$ と、その確率 $p_i = P(X = x_i)$ の対応関係。
  • 確率の総和： すべての確率の和は必ず $1$ になる。 $$p_1 + p_2 + \cdots + p_n = \sum_{i=1}^n p_i = 1$$
解法の第一歩
統計の問題では、まず「確率変数 $X$ のとり得る値をすべて書き出し、確率分布表を作成する」ことがすべての計算の基本となる。

2. 期待値・分散・標準偏差

代表値の計算

確率変数 $X$ の平均的な値や、データの散らばり具合を表す指標。

■ 期待値（平均） $E(X)$ または $m$

$$E(X) = x_1 p_1 + x_2 p_2 + \cdots + x_n p_n = \sum_{i=1}^n x_i p_i$$

■ 分散 $V(X)$（最重要公式）

$$V(X) = E(X^2) - \{E(X)\}^2 \quad \text{（「2乗の平均」$-$「平均の2乗」）}$$

■ 標準偏差 $\sigma(X)$

$$\sigma(X) = \sqrt{V(X)}$$

分散の定義 $V(X) = E((X - m)^2)$ から計算用公式を導き出す。

【数学的証明】（$m = E(X)$ とする）

$$V(X) = E\big((X - m)^2\big) = E\big(X^2 - 2mX + m^2\big)$$ 期待値の線形性 $E(aX + b) = aE(X) + b$ を適用すると： $$V(X) = E(X^2) - 2m \cdot E(X) + m^2 = E(X^2) - 2m \cdot m + m^2 = \mathbf{E(X^2) - \{E(X)\}^2} \quad \blacksquare$$

💡 具体例： 1〜3の目が出る対等なカード（$X \in \{1, 2, 3\}$, 各確率 $1/3$）

・ 平均： $m = E(X) = \frac{1+2+3}{3} = \mathbf{2}$
・ 定義通り計算： $V(X) = \frac{(1-2)^2 + (2-2)^2 + (3-2)^2}{3} = \frac{1 + 0 + 1}{3} = \mathbf{\frac{2}{3}}$
・ 公式で計算： $E(X^2) = \frac{1^2+2^2+3^2}{3} = \frac{14}{3} \implies V(X) = \frac{14}{3} - 2^2 = \frac{14}{3} - 4 = \mathbf{\frac{2}{3}}$
$\to$ どちらで計算しても完全に一致し、公式の方が展開が圧倒的に楽であることが分かる！
ポイント
偏差 $(X-m)$ をそのまま平均すると $0$ になってしまうため、**2乗して平均**を取ったのが分散。展開整理することで「2乗の平均 $-$ 平均の2乗」が導かれます。
分散計算のコツ
分散の定義式 $E((X-m)^2)$ で計算すると計算が煩雑になるため、大抵は計算用公式 $V(X) = E(X^2) - (m)^2$ を使用する。

3. 確率変数の変換（$aX + b$）

計算の法則

確率変数 $X$ を $a$ 倍して $b$ 加えた変数 $Y = aX + b$ の指標の変化規則。

  • 期待値： $E(aX + b) = \mathbf{a E(X) + b}$
  • 分 散： $V(aX + b) = \mathbf{a^2 V(X)}$ （※ $b$ の平行移動は散らばりに無関係）
  • 標準偏差： $\sigma(aX + b) = \mathbf{|a| \sigma(X)}$

💡 具体例： $E(X) = 5, \ V(X) = 4, \ \sigma(X) = 2$ のとき、 $\mathbf{Y = 2X + 10}$ を計算

・ 平均： $E(Y) = 2 \times 5 + 10 = \mathbf{20}$
（中心が2倍に伸びて、右に10ズレる）
・ 分散： $V(Y) = 2^{\mathbf{2}} \times 4 = \mathbf{16}$
（横幅が2倍 $\to$ 2乗の散らばりは $2^2 = 4$ 倍。$+10$ は無視）

【数学的証明】

・ 期待値： $E(aX+b) = \sum (ax_i + b)p_i = a\sum x_i p_i + b\sum p_i = \mathbf{a E(X) + b}$ $\quad (\text{※ }\sum p_i = 1)$
・ 分 散： $Y = aX+b$ の平均は $m_Y = am_X + b$ だから、偏差は $Y - m_Y = a(X - m_X)$
$\quad \implies V(aX+b) = E\big(\{a(X - m_X)\}^2\big) = E\big(a^2 (X - m_X)^2\big) = \mathbf{a^2 V(X)} \quad \blacksquare$

💡 具体数値による検証： データ $X = \{1, 3, 5\}$（等確率 $1/3$）に対し $\mathbf{Y = 2X + 10}$

・ 元データ $X$： 平均 $E(X) = 3$、 分散 $V(X) = \frac{(1-3)^2 + (3-3)^2 + (5-3)^2}{3} = \mathbf{\frac{8}{3}}$
・ 変換後のデータ $Y$： $Y = \{12, 16, 20\}$
$\quad \to$ 平均 $E(Y) = \frac{12+16+20}{3} = \mathbf{16}$ $\quad (\text{公式: } 2 \times 3 + 10 = \mathbf{16}$ と一致！$)$
$\quad \to$ 分散 $V(Y) = \frac{(12-16)^2 + (16-16)^2 + (20-16)^2}{3} = \frac{16 + 0 + 16}{3} = \mathbf{\frac{32}{3}}$
$\quad \phantom{\to}$ （公式: $2^2 \times \frac{8}{3} = 4 \times \frac{8}{3} = \mathbf{\frac{32}{3}}$ と完全に一致！定数 $+10$ は散らばり幅に不与）
直感的な意味
全体を $+10$ してもデータ同士の間隔（散らばり）は一切広がらないため分散に影響しません。一方、$2$倍するとデータ間隔も $2$倍になり、2乗して計算する分散は **$2^2 = 4$倍** に広がります。
標準化（規格化）への応用例
平均 $m=50$、標準偏差 $\sigma=10$ のデータも、 $Z = \frac{X - 50}{10} = \frac{1}{10}X - 5$ と変換すれば、
平均 $E(Z) = \frac{1}{10}(50) - 5 = \mathbf{0}$、 分散 $V(Z) = \left(\frac{1}{10}\right)^2 \times 10^2 = \mathbf{1}$ にピッタリ変換（標準化）できる。

4. 二項分布 $B(n, p)$

最重要分布

1回の試行で事象の起こる確率が $p$ である独立試行を $n$ 回行うときの確率分布。

■ 確率質量関数

$$P(X = k) = {}_n\text{C}_k \, p^k (1-p)^{n-k} \quad (k = 0, 1, \dots, n)$$

■ 二項分布 $B(n, p)$ の平均・分散公式（超頻出）

$$\text{期待値： } E(X) = \mathbf{np}$$ $$\text{分 散： } V(X) = \mathbf{np(1-p)} \quad \left(\text{※ } q = 1-p \text{ とおくと } npq\right)$$
公式の威力
通常通り定義から計算すると複雑な和になるが、二項分布と見抜ければ $E(X)=np, V(X)=np(1-p)$ で一瞬で計算が完了する。

二項分布 E(X)=np, V(X)=npq の導出

最重要分布のからくり

【導出の考え方】 1回の試行で成功なら1、失敗なら0をとる変数 $X_i$ の和と捉える

1回の試行 $X_i$ の平均 $E(X_i) = 1 \cdot p + 0 \cdot (1-p) = p$
1回の試行 $X_i$ の分散 $V(X_i) = E(X_i^2) - (E(X_i))^2 = p - p^2 = p(1-p)$
二項分布 $X$ は $n$ 回の独立な和 $X = X_1 + X_2 + \cdots + X_n$ だから：
・ 期待値： $E(X) = E(X_1) + \cdots + E(X_n) = p + \cdots + p = \mathbf{np}$
・ 分 散： 独立より $V(X) = V(X_1) + \cdots + V(X_n) = \mathbf{np(1-p)} \quad \blacksquare$

💡 具体例： コインを 3回 投げて表が出る回数 $X \sim B\left(3, \frac{1}{2}\right)$

・ 確率分布： $P(X=0)=\frac{1}{8}, \ P(X=1)=\frac{3}{8}, \ P(X=2)=\frac{3}{8}, \ P(X=3)=\frac{1}{8}$
・ 定義から計算した平均： $E(X) = 0\cdot\frac{1}{8} + 1\cdot\frac{3}{8} + 2\cdot\frac{3}{8} + 3\cdot\frac{1}{8} = \frac{12}{8} = \mathbf{1.5}$
$\quad \to$ 公式： $E(X) = np = 3 \times \frac{1}{2} = \mathbf{1.5}$ （一致！）
・ 定義から計算した分散： $E(X^2) = 0\cdot\frac{1}{8} + 1\cdot\frac{3}{8} + 4\cdot\frac{3}{8} + 9\cdot\frac{1}{8} = \frac{24}{8} = 3 \implies V(X) = 3 - (1.5)^2 = \mathbf{0.75}$
$\quad \to$ 公式： $V(X) = np(1-p) = 3 \times \frac{1}{2} \times \frac{1}{2} = \mathbf{0.75}$ （一致！）
なぜこの証明が強力か
$\sum k {}_n\text{C}_k p^k q^{n-k}$ のような複雑なシグマ計算をしなくても、「1回あたりの期待値 $p$ と分散 $pq$ を $n$ 個足し合わせる」と捉えることで、一瞬で公式が導出できます。

演習問題［1］：期待値と分散

基本レベル
【問題】
1個のさいころを投げるとき、出る目を $X$ とする。$X$ の期待値 $E(X)$、分散 $V(X)$、標準偏差 $\sigma(X)$ を求めよ。
解答・解説
各目の確率はすべて $\frac{1}{6}$ である。
・ 期待値： $E(X) = (1+2+3+4+5+6) \times \frac{1}{6} = \frac{21}{6} = \mathbf{\frac{7}{2}}$
・ 2乗の平均： $E(X^2) = (1^2+2^2+3^2+4^2+5^2+6^2) \times \frac{1}{6} = \frac{91}{6}$
・ 分散： $V(X) = E(X^2) - \{E(X)\}^2 = \frac{91}{6} - \left(\frac{7}{2}\right)^2 = \frac{91}{6} - \frac{147}{12} = \mathbf{\frac{35}{12}}$
・ 標準偏差： $\sigma(X) = \sqrt{\frac{35}{12}} = \mathbf{\frac{\sqrt{105}}{6}}$

演習問題［2］：確率変数の変換

標準レベル
【問題】
確率変数 $X$ の期待値が $E(X) = 3$、分散が $V(X) = 4$ であるとき、
$Y = 2X - 5$ についての期待値 $E(Y)$、分散 $V(Y)$、標準偏差 $\sigma(Y)$ を求めよ。
解答・解説
変換公式 $Y = aX + b$ を適用する。
・ 期待値： $E(Y) = 2 E(X) - 5 = 2(3) - 5 = \mathbf{1}$
・ 分 散： $V(Y) = 2^2 V(X) = 4 \times 4 = \mathbf{16}$
・ 標準偏差： $\sigma(Y) = \sqrt{V(Y)} = \sqrt{16} = \mathbf{4}$ （または $|2| \sigma(X) = 2 \times 2 = 4$）

演習問題［3］：二項分布の応用

頻出レベル
【問題】
1枚のコインを 100回 投げるとき、表が出る回数を $X$ とする。
(1) $X$ の期待値 $E(X)$、分散 $V(X)$ を求めよ。
(2) 表がちょうど 50回 出る確率 $P(X = 50)$ を式で表せ。
解答・解説
$X$ は二項分布 $B\left(100, \frac{1}{2}\right)$ に従う。
(1) 期待値・分散：
・ $E(X) = np = 100 \times \frac{1}{2} = \mathbf{50}$
・ $V(X) = np(1-p) = 100 \times \frac{1}{2} \times \frac{1}{2} = \mathbf{25}$

(2) 確立の式：
$$P(X = 50) = {}_{100}\text{C}_{50} \left(\frac{1}{2}\right)^{50} \left(\frac{1}{2}\right)^{50} = \mathbf{{}_{100}\text{C}_{50} \left(\frac{1}{2}\right)^{100}}$$

演習問題［4］：分布表の未定係数

頻出レベル
【問題】
確率変数 $X$ のとる値が $1, 2, 3$ であり、それぞれの確率が $P(X = k) = c k^2 \ (k=1, 2, 3)$ で与えられている。
(1) 定数 $c$ の値を求めよ。
(2) $X$ の期待値 $E(X)$ を求めよ。
解答・解説
(1) 確率の総和 $= 1$ を利用：
$P(X=1) = c(1^2) = c, \quad P(X=2) = c(2^2) = 4c, \quad P(X=3) = c(3^2) = 9c$
確率の和は $1$ になるので： $c + 4c + 9c = 1 \implies 14c = 1 \implies \mathbf{c = \frac{1}{14}}$

(2) 期待値の計算：
$$E(X) = 1 \cdot (c) + 2 \cdot (4c) + 3 \cdot (9c) = c + 8c + 27c = 36c$$ $c = \frac{1}{14}$ を代入して： $E(X) = 36 \times \frac{1}{14} = \mathbf{\frac{18}{7}}$

5. 連続確率変数と正規分布

発展発展

確率変数が連続的な値をとる場合、面積が確率を表す（確率密度関数 $f(x)$）。

■ 確率と面積

$$P(a \leqq X \leqq b) = \text{（区間 }[a, b] \text{ における } y = f(x) \text{ と } x \text{ 軸の間の面積）}$$

■ 正規分布 $N(m, \sigma^2)$ の標準化

$$X \sim N(m, \sigma^2) \text{ のとき、 } Z = \frac{X - m}{\sigma} \ \implies \ Z \sim N(0, 1) \text{ （標準正規分布）}$$
正規分布の着眼点
どんな平均 $m$ や標準偏差 $\sigma$ の正規分布でも、$Z = \frac{X-m}{\sigma}$ により標準正規分布 $N(0,1)$ に変換すれば正規分布表から確率を読み取れるようになる。

演習問題［5］：正規分布の確率

応用レベル
【問題】
ある試験の点数 $X$ が、平均 $60$、標準偏差 $10$ の正規分布 $N(60, 10^2)$ に従うとき、点数が $70$点以上となる確率 $P(X \geqq 70)$ を求めよ。
（※ ただし、標準正規分布 $N(0,1)$ において $P(0 \leqq Z \leqq 1) = 0.3413$ とする）
解答・解説
標準化を行う：
$Z = \frac{X - 60}{10}$ と置くと、$Z$ は標準正規分布 $N(0, 1)$ に従う。
$X = 70$ のとき、 $Z = \frac{70 - 60}{10} = 1$ である。
求める確率は：
$$P(X \geqq 70) = P(Z \geqq 1) = 0.5 - P(0 \leqq Z \leqq 1) = 0.5 - 0.3413 = \mathbf{0.1587}$$

確率分布と期待値のまとめ

総括
  1. 確率分布表の作成： $\sum p_i = 1$ を最優先でチェックする。
  2. 代表値の計算： 分散は $V(X) = E(X^2) - (E(X))^2$ を使う。
  3. 変数の変換： $E(aX+b) = aE(X)+b$、 $V(aX+b) = a^2V(X)$。
  4. 二項分布 $B(n, p)$： $E(X) = np$, $V(X) = np(1-p)$。
  5. 正規分布の活用： $Z = \frac{X-m}{\sigma}$ で標準化して確率を求める。
学習のアドバイス
統計分野は「公式の成り立ち（確率分布の定義）」と「変換・標準化の手順」さえマスターすれば、計算パターンが一定のため非常に得点源にしやすい分野です。
