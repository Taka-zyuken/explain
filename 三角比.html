数学Ⅰ_三角比

直角三角形の定義・単位円拡張・正弦余弦定理・三角形の計量

キーボードの「→」キー、または画面下のボタンで進む仕様である。

1. 鋭角の三角比（直角三角形）

三角比の原点

直角三角形の辺の長さの比として定義される（$\theta$ を左下、直角を右下に配置）。

$$\sin\theta = \frac{\text{対辺}}{\text{斜辺}} = \frac{r}{r_{hyp}} \quad \text{（sの筆記体）}$$ $$\cos\theta = \frac{\text{底辺}}{\text{斜辺}} = \frac{c}{r_{hyp}} \quad \text{（cのなぞり）}$$ $$\tan\theta = \frac{\text{対辺}}{\text{底辺}} = \frac{r}{c} \quad \text{（tの筆記体）}$$
特別な角の三角比（暗記必須）
・ $30^\circ, 45^\circ, 60^\circ$ の三角比は、1:2:$\sqrt{3}$ および 1:1:$\sqrt{2}$ の直角三角形から即座に導出できるようにする。

2. 単位円による定義の拡張（0°〜180°）

鈍角への拡張

半径 $1$ の半円（単位円）上の点 $\text{P}(x, y)$ の座標として定義し、鈍角まで拡張する。

  • $\cos\theta = x$ 座標 （横の動き）
  • $\sin\theta = y$ 座標 （縦の動き）
  • $\tan\theta = \text{直線 } \text{OP} \text{ の傾き}$

鈍角（$90^\circ < \theta \leqq 180^\circ$）の符号：
$\cos\theta < 0$, $\tan\theta < 0$ となり、$\sin\theta$ のみ正（$y > 0$）をとる！

補角・余角の公式
・ 補角（$180^\circ - \theta$）： $\sin(180^\circ-\theta) = \sin\theta, \ \cos(180^\circ-\theta) = -\cos\theta$
・ 余角（$90^\circ - \theta$）： $\sin(90^\circ-\theta) = \cos\theta, \ \cos(90^\circ-\theta) = \sin\theta$

3. 三角比の相互関係

変形・計算の公式

1つの三角比が分かれば、相互関係を用いて残り2つの三角比を導出できる。

■ 三角比の 3大相互関係公式

$$\text{① } \mathbf{\tan\theta = \frac{\sin\theta}{\cos\theta}}$$
$$\text{② } \mathbf{\sin^2\theta + \cos^2\theta = 1}$$
$$\text{③ } \mathbf{1 + \tan^2\theta = \frac{1}{\cos^2\theta}}$$
解法のポイント（符号の判定）
$\sin^2\theta + \cos^2\theta = 1$ から $\cos\theta$ を求める際、$\cos\theta = \pm \sqrt{1 - \sin^2\theta}$ となる。
$\theta$ が鋭角（$0^\circ < \theta < 90^\circ$）なら正、鈍角（$90^\circ < \theta < 180^\circ$）なら負 になるため、角の範囲の確認が必須！

4. 正弦定理と余弦定理

最重要定理

$\triangle\text{ABC}$ の 3辺を $a, b, c$、外接円の半径を $R$ としたときの定理。

■ 正弦定理（向かい合う「辺と角」＋ 外接円）

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

■ 余弦定理（「2辺と挟む角」または「3辺」）

$$a^2 = b^2 + c^2 - 2bc \cos A \quad \iff \quad \mathbf{\cos A = \frac{b^2 + c^2 - a^2}{2bc}}$$
使い分けの判断基準
・ 正弦定理を使う時： 「2角と1辺」 または 「外接円の半径 $R$」 が絡むとき
・ 余弦定理を使う時： 「2辺と挟む角」 または 「3辺の長さ」 が与えられているとき

5. 三角形の面積と内接円

図形の計量

2辺と挟む角のサインを用いた面積公式と、内接円の半径 $r$ との関係。

■ 面積公式 $S$

$$S = \frac{1}{2}bc \sin A = \frac{1}{2}ca \sin B = \frac{1}{2}ab \sin C$$

■ 内接円の半径 $r$ との相関

$$S = \frac{1}{2} r (a + b + c) \quad \implies \quad \mathbf{r = \frac{2S}{a + b + c}}$$
ヘロンの公式（3辺から直接面積）
$s = \frac{a+b+c}{2}$ とおくと、 $\mathbf{S = \sqrt{s(s-a)(s-b)(s-c)}}$
（3辺の長さが整数の場合、余弦定理 $\to \sin$ 変換を経ずに一瞬で面積を導出できる）

演習問題［1］：三角比の相互関係

基本レベル
【問題】
$\theta$ は鈍角とする。$\sin\theta = \frac{3}{5}$ のとき、 $\cos\theta$ および $\tan\theta$ の値を求めよ。
解答・解説
$\sin^2\theta + \cos^2\theta = 1$ より、 $\cos^2\theta = 1 - \left(\frac{3}{5}\right)^2 = 1 - \frac{9}{25} = \frac{16}{25}$
$\theta$ は鈍角（$90^\circ < \theta < 180^\circ$）なので $\cos\theta < 0$ である。
したがって、 $\mathbf{\cos\theta = -\sqrt{\frac{16}{25}} = -\frac{4}{5}}$

また、 $\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{3/5}{-4/5} = \mathbf{-\frac{3}{4}}$

演習問題［2］：正弦定理・余弦定理の活用

標準レベル
【問題】
$\triangle\text{ABC}$ において、$b = \sqrt{6}, \ c = 2, \ B = 60^\circ$ のとき、辺 $a$ の長さおよび外接円の半径 $R$ を求めよ。
解答・解説
■ 外接円の半径 $R$ （正弦定理）：
$\frac{b}{\sin B} = 2R \implies 2R = \frac{\sqrt{6}}{\sin 60^\circ} = \frac{\sqrt{6}}{\sqrt{3}/2} = 2\sqrt{2} \implies \mathbf{R = \sqrt{2}}$

■ 辺 $a$ の長さ（余弦定理）：
$b^2 = a^2 + c^2 - 2ac \cos B$ に代入して：
$(\sqrt{6})^2 = a^2 + 2^2 - 2 \cdot a \cdot 2 \cos 60^\circ \implies 6 = a^2 + 4 - 2a \implies a^2 - 2a - 2 = 0$
解の公式より $a = 1 \pm \sqrt{3}$。 $a > 0$ であるため、 $\mathbf{a = 1 + \sqrt{3}}$

演習問題［3］：面積と内接円の半径

標準・頻出
【問題】
3辺の長さが $a = 5, \ b = 6, \ c = 7$ である $\triangle\text{ABC}$ の面積 $S$、および内接円の半径 $r$ を求めよ。
解答・解説
■ 面積 $S$ （ヘロンの公式）：
$s = \frac{5 + 6 + 7}{2} = 9$ である。
$S = \sqrt{9(9-5)(9-6)(9-7)} = \sqrt{9 \times 4 \times 3 \times 2} = \mathbf{6\sqrt{6}}$

■ 内接円の半径 $r$：
$S = \frac{1}{2} r (a + b + c)$ より、 $6\sqrt{6} = \frac{1}{2} r (5 + 6 + 7) \implies 6\sqrt{6} = 9r$
したがって、 $\mathbf{r = \frac{6\sqrt{6}}{9} = \frac{2\sqrt{6}}{3}}$

演習問題［4］：空間への応用（測量）

応用レベル
【問題】
水平な地面の点 $\text{A}, \text{B}$ 間の距離が $100\text{m}$ である。塔の頂上 $\text{P}$ を見上げた仰角が、点 $\text{A}$ からは $30^\circ$、点 $\text{B}$ からは $45^\circ$ であった。また $\angle\text{AQB} = 30^\circ$ （$\text{Q}$ は塔の足）であるとき、塔の高さ $\text{PQ}$ を求めよ。
解答・解説
塔の高さを $h = \text{PQ}$ と置く。
直角三角形 $\triangle\text{PQA}$ より $\text{AQ} = \frac{h}{\tan 30^\circ} = \sqrt{3}h$
直角三角形 $\triangle\text{PQB}$ より $\text{BQ} = \frac{h}{\tan 45^\circ} = h$
地面の $\triangle\text{ABQ}$ において、余弦定理を適用する：
$$\text{AB}^2 = \text{AQ}^2 + \text{BQ}^2 - 2(\text{AQ})(\text{BQ})\cos\angle\text{AQB}$$ $$100^2 = (\sqrt{3}h)^2 + h^2 - 2(\sqrt{3}h)(h)\cos 30^\circ = 3h^2 + h^2 - 3h^2 = h^2$$ $h^2 = 10000 \implies h > 0$ より、 塔の高さは $\mathbf{100\text{m}}$

三角比のまとめ

総括
  1. 定義の拡張： $\cos\theta$ は $x$ 座標、 $\sin\theta$ は $y$ 座標（鈍角の符号に注意）。
  2. 相互関係： $\tan\theta = \frac{\sin}{\cos}$ や $\sin^2+\cos^2=1$ で1つの三角比から他を展開。
  3. 正弦・余弦定理： 条件（角の数、対向辺、3辺など）に応じて素早く使い分ける。
  4. 計量と応用： $S = \frac{1}{2}ab\sin C$ や内接円 $r$ の連動公式で図形問題を攻略する。
学習のアドバイス
三角比は平面図形のみならず、空間図形の断面・底面の三角形の立式において最強のツールになります。定理の公式を覚えるだけでなく「どんな条件のときにどちらの定理を使うか」の判断速度を上げましょう。
