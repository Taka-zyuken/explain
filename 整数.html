数学A_整数の性質

倍数・約数・素因数分解・ユークリッドの互除法・不定方程式・n進法

キーボードの「→」キー、または画面下のボタンで進む仕様である。

1. 約数の個数と総和（素因数分解）

数論の基本

自然数 $N$ が $N = p^a q^b r^c$ （$p, q, r$ は互いに異なる素数）と素因数分解できるときの公式。

■ 正の約数の個数

$$\text{個数} = \mathbf{(a + 1)(b + 1)(c + 1)}$$

■ 正の約数の総和

$$\text{総和} = \mathbf{(1 + p + p^2 + \cdots + p^a)(1 + q + q^2 + \cdots + q^b)(1 + r + \cdots + r^c)}$$
💡 具体例： $N = 360 = 2^3 \times 3^2 \times 5^1$ の場合
・ 約数の個数： $(3+1)(2+1)(1+1) = 4 \times 3 \times 2 = \mathbf{24 \text{ 個}}$
・ 約数の総和： $(1+2+4+8)(1+3+9)(1+5) = 15 \times 13 \times 6 = \mathbf{1170}$

2. 最大公約数(GCD)と最小公倍数(LCM)

互いに素

2つの自然数 $a, b$ の最大公約数を $g$、最小公倍数を $l$ としたときの構造的公式。

$a = g a', \ b = g b'$ （$a', b'$ は互いに素な自然数、即ち $\gcd(a', b') = 1$）とおける。

$$\text{① } \mathbf{l = g a' b'} \qquad \text{（最小公倍数の表し方）}$$ $$\text{② } \mathbf{ab = g \cdot l} \qquad \text{（「2数の積」$=$「最大公約数 $\times$ 最小公倍数」）}$$
「互いに素」の重要性
最大公約数 $g$ を括り出した残りの $a', b'$ に共通の素因数が残っていないこと（$\gcd(a', b')=1$）が、整数問題の立式における必要不可欠な前提条件となる。

3. ユークリッドの互除法

巨大な数のGCD

大きい数同士の最大公約数を「割り算のあまり」を繰り返すことで効率的に導出する。

■ 互除法の原理

$a$ を $b$ で割った商を $q$、余りを $r$ とすると （$a = bq + r$）
$$\mathbf{\gcd(a, b) = \gcd(b, r)} \quad \text{（「a と b の最大公約数」$=$「b と 余り r の最大公約数」）}$$ 余りが $0$ になったときの最後の割り手（除数）が最大公約数となる。
💡 具体例： $\gcd(221, 153)$ を求める
・ $221 = 153 \times 1 + 68 \implies \gcd(221, 153) = \gcd(153, 68)$
・ $153 = 68 \times 2 + 17 \implies \gcd(153, 68) = \gcd(68, 17)$
・ $68 = 17 \times 4 + 0 \implies$ 余りが $0$ になったので最大公約数は $\mathbf{17}$

4. 1次不定方程式 $ax + by = c$ の解法

最重要パターン

整数解をもつ条件と、一般解を求めるための 3ステップ解法。

■ 解が存在する条件と解法手順

$a, b$ が互いに素なとき、$ax + by = 1$ には必ず整数解が存在する。
  1. 特殊解を1組見つける： $(x, y) = (x_0, y_0)$ （互除法を逆算して探索）
  2. 元の式との引き算： $a(x - x_0) + b(y - y_0) = 0 \implies a(x - x_0) = -b(y - y_0)$
  3. 「互いに素」を利用： $x - x_0 = bk \implies \mathbf{x = bk + x_0, \ y = -ak + y_0 \quad (k \in \mathbb{Z})}$
互除法の逆算（特殊解の発見）
係数が大きく目視で特殊解が見つからない場合は、ユークリッドの互除法の計算過程を「余り $=$ 」の形に変形して代入代入で遡ることで確実に1組の解が得られる。

余り計算の強力な武器：合同式（mod）

余りの世界

割り算の「余り」だけに注目して、複雑な巨大数の計算を簡略化する表記法。

■ 合同式の定義

$a$ と $b$ を $m$ で割った余りが等しいとき、「$a$ と $b$ は $m$ を模として合同」といい、次のように書く。 $$\mathbf{a \equiv b \pmod{m}} \iff \mathbf{a - b \text{ は } m \text{ の倍数}}$$ （例： $17 \equiv 3 \pmod{7}$ は、17 も 3 も 7 で割った余りが 3 であることを意味する）

■ 合同式の 4大性質（$a \equiv b, \ c \equiv d \pmod{m}$ のとき）

・ 足し算・引き算： $a \pm c \equiv b \pm d \pmod{m}$
・ 掛け算： $a \cdot c \equiv b \cdot d \pmod{m}$
・ 累乗（最重要）： $\mathbf{a^k \equiv b^k \pmod{m}}$ （何乗しても余りの関係は保たれる！）
💡 具体例： $3^{100}$ を 7 で割った余りを求める
$3^1 \equiv 3$, $\ 3^2 \equiv 2$, $\ \mathbf{3^3 = 27 \equiv -1 \pmod{7}}$ に着目する。
両辺を 33 乗すると： $(3^3)^{33} \equiv (-1)^{33} \implies 3^{99} \equiv -1 \pmod{7}$
両辺に 3 を掛けると： $3^{100} \equiv -1 \times 3 = -3 \equiv \mathbf{4 \pmod{7}}$ $\to$ 余りは 4

n進法の仕組みと相互変換

記数法

「$n$ 個集まると上の位へ繰り上がる」考え方。日常の10進数を基軸に構造を理解する。

■ n進数の位取り（重み付け）

$n$ 進数 $a_3 a_2 a_1 a_0 \ _{(n)}$ は、各桁に $n^0, n^1, n^2, n^3 \dots$ の重みがついている。 $$a_3 a_2 a_1 a_0 \ _{(n)} = a_3 \times n^3 + a_2 \times n^2 + a_1 \times n^1 + a_0 \times n^0$$ （例： 2進数は $0, 1$ の2つの数字のみ、5進数は $0, 1, 2, 3, 4$ の5つの数字のみで表現する）

■ 10進数 と n進数 の相互変換アルゴリズム

・ n進数 $\to$ 10進数： 各桁に $n^k$ を掛けて展開して足し合わせる。
・ 10進数 $\to$ n進数： もとの数を $n$ で割り続け、商が $0$ になるまでの「あまり」を逆順に並べる。
💡 少数への拡張（n進小数の重み）
小数点の右側は $\frac{1}{n}, \frac{1}{n^2}, \frac{1}{n^3} \dots$ の重みがつく。
例： $0.11_{(2)} = 1 \times \frac{1}{2^1} + 1 \times \frac{1}{2^2} = \frac{1}{2} + \frac{1}{4} = \mathbf{0.75}$

整数問題を解くための3原則（解法のTips）

アプローチの鉄則

未知の整数問題を前にしたとき、まずは以下の3原則のどれに当てはめるかを検討する。

① 足し算は掛け算になるべく直す（積の形を作る）

・ 狙い： 「整数 $\times$ 整数 $=$ 整数（定数）」の形を作ることで、約数の候補に絞り込む。
・ 例： $xy - 2x - 3y = 0 \implies (x - 3)(y - 2) = 6$ （6の約数ペアに限定できる）

② 倍数・あまりに着目する（周期性・合同式）

・ 狙い： 余りで分類して不可能なケースを排除する（奇数・偶数、3で割った余りなど）。
・ 例： $n^2$ を 3 で割った余りは $0$ か $1$ にしかならない（$2$ には絶対にならない）ことを利用する。

③ 範囲・条件で絞る（不等式の活用）

・ 狙い： 解の候補が無限に広がらないよう、不等式を作って有限個に追い詰める。
・ 例： $a \leqq b \leqq c$ のとき $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} = 1 \implies 1 \leqq \frac{3}{a} \implies a \leqq 3$
思考のフロー
問題文に「整数解を求めよ」「自然数 $n$」とあったら、まずは 「積の形（①）」$\to$ 「あまりの分類（②）」$\to$ 「範囲の絞り込み（③）」 の順で突破口を探すのが定石です。

演習問題［1］：約数の個数と総和

基本レベル
【問題】
$200$ の正の約数の個数、およびそれらの総和を求めよ。
解答・解説
まず $200$ を素因数分解する：
$$200 = 2^3 \times 5^2$$ ・ 正の約数の個数：
$\quad (3 + 1)(2 + 1) = 4 \times 3 = \mathbf{12 \text{ 個}}$

・ 正の約数の総和：
$\quad (1 + 2 + 2^2 + 2^3)(1 + 5 + 5^2) = (1 + 2 + 4 + 8)(1 + 5 + 25) = 15 \times 31 = \mathbf{465}$

演習問題［2］：2整数の決定

標準レベル
【問題】
最大公約数が $12$、最小公倍数が $180$ である 2つの自然数 $a, b$ ($a < b$) の組をすべて求めよ。
解答・解説
$a = 12a', \ b = 12b'$ （$a', b'$ は互いに素な自然数で $a' < b'$）とおける。
最小公倍数の条件より： $12 a' b' = 180 \implies a' b' = 15$
積が $15$ であり、互いに素かつ $a' < b'$ を満たす自然数 $(a', b')$ の組は：
$\quad (a', b') = (1, 15), \ (3, 5)$
それぞれ $12$ 倍して求める自然数 $(a, b)$ の組は：
$\quad \mathbf{(a, b) = (12, 180), \ (36, 60)}$

演習問題［3］：1次不定方程式 ax+by=1

標準・頻出
【問題】
方程式 $7x - 3y = 1$ のすべての整数解（一般解）を求めよ。
解答・解説
・ 特殊解の発見： $x = 1, y = 2$ は $7(1) - 3(2) = 1$ を満たす。
・ 引き算：
$$\begin{aligned} 7x - 3y &= 1 \\ -) \ 7(1) - 3(2) &= 1 \\ \hline 7(x - 1) - 3(y - 2) &= 0 \implies 7(x - 1) = 3(y - 2) \end{aligned}$$ $7$ と $3$ は互いに素であるため、$x - 1$ は $3$ の倍数である。即ち $x - 1 = 3k \ (k \in \mathbb{Z})$ とおける。
代入すると $7(3k) = 3(y - 2) \implies y - 2 = 7k$
したがって一般解は： $\mathbf{x = 3k + 1, \ y = 7k + 2 \quad (k \text{ は整数})}$

演習問題［4］：n進法の変換

記数法
【問題】
(1) 10進数の $43$ を 2進法で表せ。
(2) 5進法で表された数 $234_{(5)}$ を 10進法で表せ。
解答・解説
(1) 10進数 $\to$ 2進数（2で割った余りを下から並べる）：
$43 \div 2 = 21 \cdots 1$
$21 \div 2 = 10 \cdots 1$
$10 \div 2 = 5 \cdots 0$
$5 \div 2 = 2 \cdots 1$
$2 \div 2 = 1 \cdots 0 \implies 1 \div 2 = 0 \cdots 1$
余りを逆から並べて： $\mathbf{101011_{(2)}}$

(2) 5進数 $\to$ 10進数（重み付けを展開）：
$234_{(5)} = 2 \times 5^2 + 3 \times 5^1 + 4 \times 5^0 = 2 \times 25 + 3 \times 5 + 4 \times 1 = 50 + 15 + 4 = \mathbf{69}$

整数の性質のまとめ

総括
  1. 素因数分解： 全ての自然数の素構造を可視化する基本ツール（約数の個数・総和の土台）。
  2. 互いに素： $a = ga', b = gb'$ （$\gcd(a',b')=1$）や $ab = gl$ などの公約数・公倍数立式の核心。
  3. ユークリッドの互除法： 割り算の余りを追跡して大きな数のGCD導出や不定方程式の特殊解探索に活用。
  4. 1次不定方程式： 特殊解を1組見つけ、差をとって「互いに素」の条件から一般解 $k$ を導出する。
学習のアドバイス
整数の問題は「あまりに注目する（余りの分類）」「因数分解の形 $A \times B = C$（整数）を作る」「不等式で範囲を絞り込む」の3大解法アプローチが非常に有効です。パターンを押さえて解き筋を見極めましょう。
