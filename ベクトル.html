数学B/C_ベクトル（体系的解説）

平面のベクトル状態・位置ベクトル・空間ベクトル

キーボードの「→」キー、または画面下のボタンで進む仕様である。

1. ベクトルの定義と分解の原理

ベクトルの基本

ベクトルは「向き」と「大きさ」をもつ量であり、始点と終点の差として表される。

  • 合成・差： $\overrightarrow{\text{AB}} = \overrightarrow{\text{OB}} - \overrightarrow{\text{OA}}$ （後ろ $-$ 前）
  • 一次独立（基底）： $\vec{a} \neq \vec{0}, \vec{b} \neq \vec{0}, \vec{a} \nparallel \vec{b}$ のとき、平面上の任意のベクトル $\vec{p}$ は $\vec{p} = s\vec{a} + t\vec{b}$ とただ1通りに表せる。
一次独立の重要性
$s_1\vec{a} + t_1\vec{b} = s_2\vec{a} + t_2\vec{b} \iff s_1 = s_2 \ \text{かつ} \ t_1 = t_2$。係数を比較する思考の根幹となる。

2. 内積・成分表示と条件式

計算の根幹

内積は「影の長さとの積」を意味するスカラー量である。

■ 内積の定義と成分表示（$\vec{a}=(a_1, a_2), \vec{b}=(b_1, b_2)$）

$$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta = a_1 b_1 + a_2 b_2$$

■ ベクトルの平行・垂直条件（成分表示）

$$\text{平行 } (\vec{a} /\!/ \vec{b}) \ \iff \ a_1 b_2 - a_2 b_1 = 0 \quad (\vec{b} = k\vec{a})$$ $$\text{垂直 } (\vec{a} \perp \vec{b}) \ \iff \ a_1 b_1 + a_2 b_2 = 0 \quad (\vec{a} \cdot \vec{b} = 0)$$
絶対値の自乗展開
$|\vec{a} + t\vec{b}|^2 = |\vec{a}|^2 + 2t(\vec{a} \cdot \vec{b}) + t^2|\vec{b}|^2$ のように、大きさを2乗して内積の形を作る処理は超頻出。

3. 位置ベクトルと分点・重心

図形の性質

基準点 $\text{O}$ から見た各点の位置ベクトル $\vec{a}, \vec{b}, \vec{c}$ による表現。

  • 内分点 $\text{P}$： $\vec{p} = \frac{n\vec{a} + m\vec{b}}{m+n}$
  • 外分点 $\text{Q}$： $\vec{q} = \frac{-n\vec{a} + m\vec{b}}{m-n}$
  • $\triangle\text{ABC}$ の重心 $\text{G}$： $\vec{g} = \frac{\vec{a} + \vec{b} + \vec{c}}{3}$
重心の性質
重心 $\text{G}$ は中線 $\text{AM}$ を $2:1$ に内分する点であるため、 $\vec{g} = \frac{\vec{a} + 2\left(\frac{\vec{b}+\vec{c}}{2}\right)}{1+2} = \frac{\vec{a}+\vec{b}+\vec{c}}{3}$ と導出される。

4. 三角形の五心と位置ベクトル

発展・応用

重心以外の「心」の位置ベクトル条件（$\triangle\text{ABC}$ の頂点位置ベクトルを $\vec{a}, \vec{b}, \vec{c}$ とする）。

  • 推進（垂心 $\text{H}$）： $\overrightarrow{\text{AH}} \cdot \overrightarrow{\text{BC}} = 0 \ \text{かつ} \ \overrightarrow{\text{BH}} \cdot \overrightarrow{\text{CA}} = 0$ （各頂点からの垂線の交点）
  • 外心 $\text{O}$： $|\overrightarrow{\text{OA}}| = |\overrightarrow{\text{OB}}| = |\overrightarrow{\text{OC}}| = R$ （外接円の半径）
  • 内心 $\text{I}$： 各辺の長さを $a, b, c$ としたとき $\quad \vec{i} = \frac{a\vec{a} + b\vec{b} + c\vec{c}}{a + b + c}$
オイラー線の関係
外心 $\text{O}$、重心 $\text{G}$、垂心 $\text{H}$ は一直線上に並び（オイラー線）、$\overrightarrow{\text{OH}} = 3\overrightarrow{\text{OG}}$ （$\vec{h} = \vec{a} + \vec{b} + \vec{c}$） が成立する。

直線のベクトル方程式

図形と方程式
💡 導入の理論： 一次独立な2つのベクトル $\vec{a}, \vec{b}$（平行でなく $\vec{0}$ でない）があれば、2次元平面上のすべてのベクトルは $\vec{p} = s\vec{a} + t\vec{b}$ と表せる。
$\to$ この係数 $s, t$ に「特定の制限」を与えることで、平面全体の点の中から「直線上の点」だけを絞り出すことができる。

① 異なる2点 $\text{A}(\vec{a}), \text{B}(\vec{b})$ を通る直線（係数和 $= 1$）

平面上の任意の点表現 $\vec{p} = s\vec{a} + t\vec{b}$ に対し、係数の和を $s + t = 1$ に制限すると、点 $\text{P}$ は直線 $\text{AB}$ 上のみを動く。 $$\vec{p} = (1 - t)\vec{a} + t\vec{b} \quad (t \text{ は実数})$$

② 1点 $\text{A}(\vec{a})$ を通り 方向 $\vec{d}$ に平行な直線

点 $\text{A}$ から方向ベクトル $\vec{d}$ に沿って伸縮（$t$ 倍）させる。 $$\vec{p} = \vec{a} + t\vec{d} \quad (t \text{ は実数})$$
思考のステップまとめ
① 平面全域を表す（自由度2）： $\vec{p} = s\vec{a} + t\vec{b}$ （$s, t$ は自由な実数）
② 直線に絞る（自由度1）： $s + t = 1$ という制約（等式1つ）を加えることで、2次元平面から1次元の「直線」を取り出すことができる。

点の存在範囲［1］：基礎パターン

ベクトルの領域

$\overrightarrow{\text{OP}} = s\overrightarrow{\text{OA}} + t\overrightarrow{\text{OB}}$ における係数 $s, t$ の条件と点 $\text{P}$ の動く範囲。

  • $s + t = 1$ ： 直線 $\text{AB}$
    （※ $s \geqq 0, t \geqq 0$ が付けば線分 $\text{AB}$）
  • $s + t \leqq 1 \ (s \geqq 0, t \geqq 0)$ ： $\triangle\text{OAB}$ の周および内部
  • $0 \leqq s \leqq 1, \ 0 \leqq t \leqq 1$ ： 平行四辺形 $\text{OACB}$ の周および内部
思考のポイント：斜交座標
$\overrightarrow{\text{OA}}$ と $\overrightarrow{\text{OB}}$ をそれぞれ $x$ 軸・$y$ 軸のように見立てる「斜交座標」として捉えると、通常の直交座標平面上の領域問題（$x+y=1$ や $x+y \leqq 1$ など）とまったく同じ構造であることが理解しやすい。

点の存在範囲［2］：変形・応用パターン

係数処理

係数の和が $1$ 以外（$s + t = k$ や $a s + b t \leqq k$）の場合の変形手順。

■ 変形ステップ（例: $2s + 3t \leqq 6, \ s \geqq 0, \ t \geqq 0$）

  1. Step 1： 右辺を $1$ にするために全体を $6$ で割る。
    $$\frac{s}{3} + \frac{t}{2} \leqq 1$$
  2. Step 2： $s' = \frac{s}{3}, \ t' = \frac{t}{2}$ と置き換えて $s' + t' \leqq 1$ の形を作る。
  3. Step 3： 式を新基底で書き直す。
    $$\overrightarrow{\text{OP}} = s'\underbrace{(3\overrightarrow{\text{OA}})}_{\overrightarrow{\text{OA'}}} + t'\underbrace{(2\overrightarrow{\text{OB}})}_{\overrightarrow{\text{OB'}}}$$
結論のまとめ
点 $\text{P}$ は $\text{A'}(3\text{A})$ と $\text{B'}(2\text{B})$ を頂点とする $\triangle\text{OA'B'}$ の周および内部を動く。面積は元の $\triangle\text{OAB}$ の $3 \times 2 = 6$ 倍となる。

点の存在範囲［3］：台形・帯状領域

不等式挟み

条件が範囲（$1 \leqq s + t \leqq 2$ など）で与えられるパターンの図形。

  • $1 \leqq s + t \leqq 2 \ (s \geqq 0, t \geqq 0)$ ：
    $s + t = 1$（線分 $\text{AB}$）と $s + t = 2$（線分 $\text{A'B'}$）に挟まれた台形領域。
  • $1 \leqq s \leqq 2, \ 0 \leqq t \leqq 1$ ：
    $s$ の範囲が引き延ばされた平行四辺形（または帯状）領域。
領域判定のコツ
等式（$=$）は「線」を表し、不等式（$\leqq, \geqq$）は「面（領域）」を表す。限界となる境界線（$s+t=1$ と $s+t=2$）をまず描き、その間を塗りつぶすと間違いがない。

点の存在範囲：図示の思考ステップ

解き方フロー

どんな複雑な条件でも、次の3ステップで確実に図示・イメージ化できる。

【例】 $s + 2t \leqq 2, \ s \geqq 0, \ t \geqq 0$ の場合

Step 1：最大値までベクトルを伸ばす
$s, t$ の単独での最大値を求める。
・ $t=0 \implies s$ の最大値は $2 \ \implies \mathbf{\overrightarrow{\text{OA'}} = 2\overrightarrow{\text{OA}}}$
・ $s=0 \implies t$ の最大値は $1 \ \implies \mathbf{\overrightarrow{\text{OB'}} = 1\overrightarrow{\text{OB}}}$
Step 2：角点（端点）同士を結ぶ
等号成立（$s + 2t = 2$）の境界線を作るため、伸ばした端点 $\text{A'}, \text{B'}$ 同士を直線・線分で結ぶ。
Step 3：条件範囲を塗る（斜線イメージ）
不等号（$\leqq$ や $\geqq$）に合わせて、境界線の内側（原点側）や挟まれた領域を斜線で囲む。
この思考法のメリット
複雑な式変形（$s' + t' \leqq 1$ など）で混乱したときでも、「$s$ だけ・$t$ だけの限界点（角点）を求めて結ぶ」という幾何的なアプローチをとることで、瞬時に領域の全貌と境界線をイメージできるようになります。

円のベクトル方程式

図形と方程式

円上の点 $\text{P}(\vec{p})$ が満たすべきベクトルの条件（2大基本型）。

① 中心 $\text{C}(\vec{c})$・半径 $r$ の円（距離一定）

$$|\vec{p} - \vec{c}| = r \quad \iff \quad |\vec{p} - \vec{c}|^2 = r^2$$ （※ 原点中心なら $|\vec{p}| = r$）

② 2点 $\text{A}(\vec{a}), \text{B}(\vec{b})$ を直径の両端とする円

$$\overrightarrow{\text{AP}} \cdot \overrightarrow{\text{BP}} = 0 \quad \iff \quad (\vec{p} - \vec{a}) \cdot (\vec{p} - \vec{b}) = 0$$ （※ 直径に対する円周角は $90^\circ \implies$ 内積 $0$）
判別式・変形のコツ
問題文で $2\vec{p} \cdot \vec{p} - 4\vec{a} \cdot \vec{p} = 0$ のような式が与えられた場合は、両辺を係数で割り「平方完成（内積の因数分解）」の形をつくることで、中心と半径（または直径の両端）を導き出すことができます。

演習問題：ベクトルの等式と面積比

平面ベクトル 典型
【問題】
$\triangle\text{ABC}$ の内部に点 $\text{P}$ があり、$2\overrightarrow{\text{PA}} + 3\overrightarrow{\text{PB}} + 4\overrightarrow{\text{PC}} = \vec{0}$ を満たしている。
(1) 点 $\text{P}$ の位置を求めよ。
(2) $\triangle\text{PAB} : \triangle\text{PBC} : \triangle\text{PCA}$ の面積比を求めよ。
解答・解説
(1) 点 $\text{A}$ を基準に変形する：
$-2\overrightarrow{\text{AP}} + 3(\overrightarrow{\text{AB}} - \overrightarrow{\text{AP}}) + 4(\overrightarrow{\text{AC}} - \overrightarrow{\text{AP}}) = \vec{0} \ \implies \ 9\overrightarrow{\text{AP}} = 3\overrightarrow{\text{AB}} + 4\overrightarrow{\text{AC}}$
$\overrightarrow{\text{AP}} = \frac{7}{9} \cdot \left(\frac{3\overrightarrow{\text{AB}} + 4\overrightarrow{\text{AC}}}{7}\right)$ と変形できる。
辺 $\text{BC}$ を $4:3$ に内分する点を $\text{D}$ とすると、点 $\text{P}$ は 線分 $\text{AD}$ を $7:2$ に内分する点 である。

(2) 面積比（重み係数の比）：
$a\overrightarrow{\text{PA}} + b\overrightarrow{\text{PB}} + c\overrightarrow{\text{PC}} = \vec{0}$ のとき、対向する三角形の面積比は
$\triangle\text{PBC} : \triangle\text{PCA} : \triangle\text{PAB} = a : b : c$ となるため、
$\triangle\text{PAB} : \triangle\text{PBC} : \triangle\text{PCA} = \mathbf{4 : 2 : 3}$

演習問題：2直線の交点

平面ベクトル 最重要
【問題】
$\triangle\text{OAB}$ において、辺 $\text{OA}$ を $3:1$ に内分する点を $\text{C}$、辺 $\text{OB}$ を $2:3$ に内分する点を $\text{D}$ とする。線分 $\text{AD}$ と線分 $\text{BC}$ の交点を $\text{P}$ とするとき、$\overrightarrow{\text{OP}}$ を $\vec{a}=\overrightarrow{\text{OA}}, \ \vec{b}=\overrightarrow{\text{OB}}$ を用いて表せ。
解答・解説
$\overrightarrow{\text{OC}} = \frac{3}{4}\vec{a}, \quad \overrightarrow{\text{OD}} = \frac{2}{5}\vec{b}$ である。
・ 点 $\text{P}$ は線分 $\text{AD}$ 上にあるので（$s:1-s$ に内分）：
$\quad \overrightarrow{\text{OP}} = (1-s)\vec{a} + s\overrightarrow{\text{OD}} = (1-s)\vec{a} + \frac{2}{5}s\vec{b} \ \cdots \text{①}$
・ 点 $\text{P}$ は線分 $\text{BC}$ 上にあるので（$t:1-t$ に内分）：
$\quad \overrightarrow{\text{OP}} = t\overrightarrow{\text{OC}} + (1-t)\vec{b} = \frac{3}{4}t\vec{a} + (1-t)\vec{b} \ \cdots \text{②}$
$\vec{a}, \vec{b}$ は一次独立なので係数を比較して：
$1-s = \frac{3}{4}t, \quad \frac{2}{5}s = 1-t \ \implies \ s = \frac{5}{13}, \ t = \frac{12}{13}$
①に代入して： $\mathbf{\overrightarrow{\text{OP}} = \frac{8}{13}\vec{a} + \frac{2}{13}\vec{b}}$

演習問題：垂線の足と内積

平面ベクトル 応用
【問題】
$|\vec{a}| = 2, \ |\vec{b}| = 3, \ \vec{a} \cdot \vec{b} = 4$ とする。点 $\text{O}$ を始点とし $\overrightarrow{\text{OA}}=\vec{a}, \overrightarrow{\text{OB}}=\vec{b}$ とする。点 $\text{A}$ から直線 $\text{OB}$ に下ろした垂線の足を $\text{H}$ とするとき、$\overrightarrow{\text{OH}}$ を $\vec{b}$ を用いて表せ。
解答・解説
点 $\text{H}$ は直線 $\text{OB}$ 上にあるため、実数 $k$ を用いて $\overrightarrow{\text{OH}} = k\vec{b}$ と置ける。
このとき $\overrightarrow{\text{AH}} = \overrightarrow{\text{OH}} - \overrightarrow{\text{OA}} = k\vec{b} - \vec{a}$ である。
$\text{AH} \perp \text{OB}$ より、 $\overrightarrow{\text{AH}} \cdot \vec{b} = 0$ が成立する。
$$(k\vec{b} - \vec{a}) \cdot \vec{b} = 0 \ \implies \ k|\vec{b}|^2 - \vec{a} \cdot \vec{b} = 0$$ 代入して： $k \cdot 3^2 - 4 = 0 \ \implies \ 9k = 4 \ \implies \ k = \frac{4}{9}$
したがって、 $\mathbf{\overrightarrow{\text{OH}} = \frac{4}{9}\vec{b}}$

演習問題：角の二等分線と内心

平面ベクトル 頻出
【問題】
$\triangle\text{OAB}$ において、$|\overrightarrow{\text{OA}}| = 5, \ |\overrightarrow{\text{OB}}| = 3$ とする。$\angle\text{AOB}$ の二等分線と辺 $\text{AB}$ の交点を $\text{D}$ とするとき、$\overrightarrow{\text{OD}}$ を $\vec{a}=\overrightarrow{\text{OA}}, \ \vec{b}=\overrightarrow{\text{OB}}$ で表せ。
解答・解説
解法1：角の二等分線の定理（内分比）を利用する
角の二等分線の定理より、 $\text{AD} : \text{DB} = \text{OA} : \text{OB} = 5 : 3$ である。
したがって、点 $\text{D}$ は辺 $\text{AB}$ を $5 : 3$ に内分する点なので：
$$\overrightarrow{\text{OD}} = \frac{3\vec{a} + 5\vec{b}}{5 + 3} = \mathbf{\frac{3}{8}\vec{a} + \frac{5}{8}\vec{b}}$$ （※ 補足：単位ベクトル $\frac{\vec{a}}{|\vec{a}|} + \frac{\vec{b}}{|\vec{b}|}$ を合成して定数倍する方法でも導出可能）

6. 空間ベクトルの基本・球面

3次元空間

空間の点 $\text{P}(x, y, z)$ と位置ベクトル $\vec{p} = x\vec{i} + y\vec{j} + z\vec{k}$。

■ 2点間の距離・大きさ

$$|\vec{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}$$

■ 球面の方程式（中心 $\text{C}(a,b,c)$、半径 $r$）

$$(x - a)^2 + (y - b)^2 + (z - c)^2 = r^2 \quad \iff \quad |\vec{p} - \vec{c}|^2 = r^2$$
空間での共面条件
4点 $\text{A}, \text{B}, \text{C}, \text{P}$ が同一平面上にある（共面） $\iff \mathbf{\overrightarrow{\text{AP}} = s\overrightarrow{\text{AB}} + t\overrightarrow{\text{AC}}}$

7. 空間における直線・平面方程式

空間幾何

空間内の直線・平面はベクトルを用いることで明確に方程式化できる。

■ 直線の方程式（通過点 $\text{A}(\vec{a})$、方向ベクトル $\vec{d}=(l,m,n)$）

$$\frac{x - x_1}{l} = \frac{y - y_1}{m} = \frac{z - z_1}{n} \quad (= t)$$

■ 平面の方程式（通過点 $\text{A}(\vec{a})$、法線ベクトル $\vec{n}=(a,b,c)$）

$$\vec{n} \cdot (\vec{p} - \vec{a}) = 0 \quad \iff \quad a(x - x_1) + b(y - y_1) + c(z - z_1) = 0$$
法線ベクトルの威力
平面に垂直なベクトル $\vec{n}$（法線ベクトル）が分かれば、空間内の平面は一意に定まる。

演習問題：空間ベクトルの成分と距離

空間基本
【問題】
空間の3点 $\text{A}(1, 2, 3), \text{B}(3, -1, 1), \text{C}(0, 4, 1)$ について、次の問に答えよ。
(1) ベクトル $\overrightarrow{\text{AB}}$ を成分で表せ。
(2) 2点 $\text{A}, \text{B}$ 間の距離 $|\overrightarrow{\text{AB}}|$ を求めよ。
解答・解説
(1) 成分の計算（終点 $-$ 始点）：
$$\overrightarrow{\text{AB}} = (3-1, \ -1-2, \ 1-3) = \mathbf{(2, -3, -2)}$$ (2) 2点間の距離（ベクトルの大きさ）：
$$|\overrightarrow{\text{AB}}| = \sqrt{2^2 + (-3)^2 + (-2)^2} = \sqrt{4 + 9 + 4} = \mathbf{\sqrt{17}}$$

演習問題：空間ベクトルの内積

空間基本
【問題】
$\vec{a} = (1, 0, 1), \ \vec{b} = (-1, 2, 1)$ のとき、(1) 内積 $\vec{a} \cdot \vec{b}$、(2) $\vec{a}$ と $\vec{b}$ のなす角 $\theta$ を求めよ。
解答・解説
(1) 内積の計算：
$$\vec{a} \cdot \vec{b} = 1 \cdot (-1) + 0 \cdot 2 + 1 \cdot 1 = -1 + 0 + 1 = \mathbf{0}$$
(2) なす角 $\theta$： $\vec{a} \cdot \vec{b} = 0$ かつ $\vec{a} \neq \vec{0}, \vec{b} \neq \vec{0}$ より、2つのベクトルは垂直である。
したがって、 $\mathbf{\theta = 90^\circ}$

演習問題：空間の共面条件

空間頻出・最重要
【問題】
四面体 $\text{OABC}$ において、辺 $\text{OA}$ の中点を $\text{P}$、辺 $\text{AB}$ を $2:1$ に内分する点を $\text{Q}$ とする。直線 $\text{PQ}$ と平面 $\text{OBC}$ の交点を $\text{R}$ とするとき、$\overrightarrow{\text{OR}}$ を $\vec{a}=\overrightarrow{\text{OA}}, \vec{b}=\overrightarrow{\text{OB}}, \vec{c}=\overrightarrow{\text{OC}}$ を用いて表せ。
解答・解説
$\overrightarrow{\text{OP}} = \frac{1}{2}\vec{a}, \quad \overrightarrow{\text{OQ}} = \frac{\vec{a} + 2\vec{b}}{3}$ である。
点 $\text{R}$ は直線 $\text{PQ}$ 上にあるため、実数 $k$ を用いて：
$$\overrightarrow{\text{OR}} = (1-k)\overrightarrow{\text{OP}} + k\overrightarrow{\text{OQ}} = (1-k)\left(\frac{1}{2}\vec{a}\right) + k\left(\frac{\vec{a} + 2\vec{b}}{3}\right) = \left(\frac{1}{2} - \frac{1}{6}k\right)\vec{a} + \frac{2}{3}k\vec{b}$$ 点 $\text{R}$ は平面 $\text{OBC}$ 上（$\vec{a}$ の成分が $0$）にあるので：
$$\frac{1}{2} - \frac{1}{6}k = 0 \ \implies \ k = 3$$ これを代入して： $\mathbf{\overrightarrow{\text{OR}} = 2\vec{b}}$

演習問題：平面に下ろした垂線の足

空間頻出・応用
【問題】
座標空間において、3点 $\text{A}(1, 0, 0), \text{B}(0, 2, 0), \text{C}(0, 0, 3)$ がある。原点 $\text{O}$ から平面 $\text{ABC}$ に下ろした垂線の足 $\text{H}$ の座標を求めよ。
解答・解説
平面 $\text{ABC}$ の方程式は $\frac{x}{1} + \frac{y}{2} + \frac{z}{3} = 1 \ \iff \ 6x + 3y + 2z - 6 = 0$。
この平面の法線ベクトルは $\vec{n} = (6, 3, 2)$ である。
直線 $\text{OH}$ は法線ベクトルに平行であるため、実数 $k$ を用いて $\text{H}(6k, 3k, 2k)$ と置ける。
点 $\text{H}$ は平面 $\text{ABC}$ 上にあるため代入して：
