1. 弧度法（ラジアン）

概念理解

一般角を扱うため、度数法（$^\circ$）ではなく弧度法（rad）を用いる。

半径 $r$ と同じ長さ $r$ の弧に対する中心角の大きさを $1$ ラジアン（$\text{rad}$） と定める。
  • 半円（弧長 $\pi r$）の角 $\Rightarrow \mathbf{\pi \text{ rad} = 180^\circ}$
  • 全円（弧長 $2\pi r$）の角 $\Rightarrow \mathbf{2\pi \text{ rad} = 360^\circ}$
  • $1^\circ = \frac{\pi}{180} \text{ rad}$
まとめ
弧長 $l = r\theta$、面積 $S = \frac{1}{2}r^2\theta = \frac{1}{2}rl$

2. 三角関数の定義

定義

座標平面上で、原点を中心とする半径 $r$ の円と、角 $\theta$ の動径の交点を $(x, y)$ とするとき、三角関数は次のように定義される。

$$\sin\theta = \frac{y}{r}, \quad \cos\theta = \frac{x}{r}, \quad \tan\theta = \frac{y}{x}$$
単位円上の点 $\text{P}(x, y)$ の座標に対して：
  • $x$ 座標 $\Rightarrow \cos\theta$
  • $y$ 座標 $\Rightarrow \sin\theta$
  • 直線の傾き $\Rightarrow \tan\theta = \frac{y}{x}$

有名角の三角関数の値と符号

暗記・基本

■ 象限ごとの符号（＋ / －）

第1象限：すべて ＋
第2象限：$\sin$ のみ ＋
第3象限：$\tan$ のみ ＋
第4象限：$\cos$ のみ ＋

■ 主要な角の値一覧

$\theta$ $0$ $\frac{\pi}{6}\ (30^\circ)$ $\frac{\pi}{4}\ (45^\circ)$ $\frac{\pi}{3}\ (60^\circ)$ $\frac{\pi}{2}\ (90^\circ)$ $\pi\ (180^\circ)$
$\sin\theta$ $0$ $\frac{1}{2}$ $\frac{1}{\sqrt{2}}$ $\frac{\sqrt{3}}{2}$ $1$ $0$
$\cos\theta$ $1$ $\frac{\sqrt{3}}{2}$ $\frac{1}{\sqrt{2}}$ $\frac{1}{2}$ $0$ $-1$
$\tan\theta$ $0$ $\frac{1}{\sqrt{3}}$ $1$ $\sqrt{3}$ なし $0$

三角関数の性質（対称移動）

変換公式

単位円上の点 $\text{P}(\cos\theta, \sin\theta)$ の対称移動から公式を導くことができる。

■ $\frac{\pi}{2} - \theta$ （直線 $y=x$ に関して対称）

$$\sin\left(\frac{\pi}{2} - \theta\right) = \cos\theta, \quad \cos\left(\frac{\pi}{2} - \theta\right) = \sin\theta, \quad \tan\left(\frac{\pi}{2} - \theta\right) = \frac{1}{\tan\theta}$$

■ $\pi - \theta$ （$y$ 軸に関して対称）

$$\sin(\pi - \theta) = \sin\theta, \quad \cos(\pi - \theta) = -\cos\theta$$

三角関数の性質（変換のルール）

解法テクニック

$\theta + \frac{n\pi}{2}$ の形の変換は、以下の2ステップで機械的に導出できる。

Step 1：関数の変化を判定する

  • $\pi, 2\pi$ 系列 ($\theta + \pi$ など)： 関数はそのまま ($\sin \to \sin$, $\cos \to \cos$)
  • $\frac{\pi}{2}, \frac{3\pi}{2}$ 系列 ($\theta + \frac{\pi}{2}$ など)： 関数が入れ替わる ($\sin \leftrightarrow \cos$)

Step 2：符号（＋/－）を判定する

  • $\theta$ を鋭角と仮定したとき、元の角が位置する象限での元の関数の符号をつける。
適用例：$\sin\left(\theta + \frac{\pi}{2}\right)$ の場合
① $\frac{\pi}{2}$ なので $\cos\theta$ に変化。
② $\theta$ が鋭角のとき $\theta + \frac{\pi}{2}$ は第2象限。第2象限で $\sin$ は正（＋）。
$\Rightarrow$ したがって、$\sin\left(\theta + \frac{\pi}{2}\right) = +\cos\theta$

3. 三角関数の相互関係

基本公式

三角関数の間には、以下の重要な恒等式が常に成り立つ。

$$\tan\theta = \frac{\sin\theta}{\cos\theta}$$ $$\sin^2\theta + \cos^2\theta = 1$$ $$1 + \tan^2\theta = \frac{1}{\cos^2\theta}$$
ポイント
$\sin\theta, \cos\theta, \tan\theta$ のうち $1$ つの値と角の象限が分かれば、相互関係を用いて他の $2$ つの値を導出できる。

4. 加法定理

定理

2つの角の和や差に対する三角関数の展開公式である。

$$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$$ $$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$$ $$\tan(\alpha \pm \beta) = \frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta}$$

5. 2倍角と半角の公式

派生公式

加法定理において $\beta = \alpha$ と置くことで、2倍角の公式が得られる。

【2倍角の公式】

$$\sin 2\alpha = 2\sin\alpha\cos\alpha$$ $$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$$

【半角の公式】

$$\sin^2 \frac{\alpha}{2} = \frac{1 - \cos\alpha}{2}, \quad \cos^2 \frac{\alpha}{2} = \frac{1 + \cos\alpha}{2}$$

6. 三角関数の合成

応用

$\sin$ と $\cos$ の一次式を、1つの $\sin$ にまとめる変形である。

$$a\sin\theta + b\cos\theta = \sqrt{a^2 + b^2}\sin(\theta + \alpha)$$

ただし、$\cos\alpha = \frac{a}{\sqrt{a^2 + b^2}}, \quad \sin\alpha = \frac{b}{\sqrt{a^2 + b^2}}$

目的
周期や振幅を統一し、最大値・最小値や方程式の解を求める際に極めて有効である。

演習問題［1］：定義と相互関係

基本演習
【問題】
$\theta$ は第 3 象限の角で、$\sin\theta = -\frac{4}{5}$ のとき、$\cos\theta$ および $\tan\theta$ の値を求めよ。

【考え方・解答手順】

  1. Step 1： $\sin^2\theta + \cos^2\theta = 1$ より $\cos\theta$ の絶対値を求める。
  2. Step 2： 第 3 象限より $\cos\theta$ の符号（負）を決定する。
  3. Step 3： $\tan\theta = \frac{\sin\theta}{\cos\theta}$ で算出する。
解答・解説
$\cos^2\theta = 1 - \sin^2\theta = 1 - \left(-\frac{4}{5}\right)^2 = \frac{9}{25}$
$\theta$ は第 3 象限の角より $\cos\theta < 0$ であるため、 $$\cos\theta = -\sqrt{\frac{9}{25}} = \mathbf{-\frac{3}{5}}, \quad \tan\theta = \frac{-4/5}{-3/5} = \mathbf{\frac{4}{3}}$$

演習問題［2］：$\theta$ の変換公式

標準演習
【問題】
次の式を簡単にせよ。 $$\sin\left(\theta + \frac{\pi}{2}\right) + \cos(\pi - \theta) + \sin(-\theta)$$

【各項の変換チェック】

  • $\sin\left(\theta + \frac{\pi}{2}\right) \Rightarrow \mathbf{+\cos\theta}$
  • $\cos(\pi - \theta) \Rightarrow \mathbf{-\cos\theta}$
  • $\sin(-\theta) \Rightarrow \mathbf{-\sin\theta}$
解答・答え
$(\text{与式}) = \cos\theta - \cos\theta - \sin\theta = \mathbf{-\sin\theta}$

演習問題［3］：加法定理の応用

標準演習
【問題】
$\sin 75^\circ$ および $\tan 105^\circ$ の値を求めよ。

【解法のポイント】

  • $75^\circ = 45^\circ + 30^\circ$
  • $105^\circ = 60^\circ + 45^\circ$
解答・解説
$$\sin 75^\circ = \sin(45^\circ + 30^\circ) = \frac{\sqrt{2}}{2}\cdot\frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2}\cdot\frac{1}{2} = \mathbf{\frac{\sqrt{6} + \sqrt{2}}{4}}$$ $$\tan 105^\circ = \tan(60^\circ + 45^\circ) = \frac{\sqrt{3} + 1}{1 - \sqrt{3}} = \mathbf{-2 - \sqrt{3}}$$

演習問題［4］：2倍角と半角の公式

標準演習
【問題】
$\frac{\pi}{2} < \alpha < \pi$ で $\cos\alpha = -\frac{3}{5}$ のとき、$\sin 2\alpha$ および $\sin\frac{\alpha}{2}$ の値を求めよ。

【解法のステップ】

  1. $\sin\alpha = \frac{4}{5}$ を求める。
  2. $\sin 2\alpha = 2\sin\alpha\cos\alpha$ と $\sin^2\frac{\alpha}{2} = \frac{1-\cos\alpha}{2}$ を使う。
解答・解説
$$\sin 2\alpha = 2 \cdot \frac{4}{5} \cdot \left(-\frac{3}{5}\right) = \mathbf{-\frac{24}{25}}$$ $\frac{\pi}{4} < \frac{\alpha}{2} < \frac{\pi}{2}$ より $\sin\frac{\alpha}{2} > 0$ であるため、 $$\sin\frac{\alpha}{2} = \sqrt{\frac{1 - (-3/5)}{2}} = \mathbf{\frac{2\sqrt{5}}{5}}$$

7. 三角関数のグラフ（振幅と周期）

グラフの基本

基本形 $y = \sin\theta$ を基準として、係数によって波の形が変化する。

$y = A \sin(k\theta - \alpha) + B$

  • 振幅 $A$： $y$ 軸方向に $A$ 倍
  • 周期： $\sin, \cos \Rightarrow \mathbf{\frac{2\pi}{k}}$、$\tan \Rightarrow \mathbf{\frac{\pi}{k}}$
  • 平行移動： $\theta$ 軸方向に $\frac{\alpha}{k}$、$y$ 軸方向に $B$

8. 三角方程式・三角不等式

解法手順

三角方程式・不等式は、単位円を用いて視覚的に解くのが基本方針である。

■ 基本的な処理ステップ（例: $\sin\theta \geqq k$）

  1. 1. ・
    単位円を描き、直線 $y = k$ を引く。
  2. 2. ・
    円と直線の交点に対応する動径の角 $\theta$ を求める。
  3. 3. ・
    $\sin\theta \geqq k$ ならば「直線より上側の弧」に対応する $\theta$ の範囲を答える。

■ 2次方程式型（変数の統一）

$\sin^2\theta = 1 - \cos^2\theta$ を用いて1種類の三角関数に統一し、$t = \cos\theta$（または $t = \sin\theta$）と置くことで、$t$ の2次方程式（不等式）に帰着させて解く。

⚠️ 置き換えた変数 $t$ の範囲制限 $-1 \leqq t \leqq 1$ に注意する。

演習問題［5］：三角不等式

標準演習
【問題】
$0 \leqq \theta < 2\pi$ のとき、不等式 $2\cos^2\theta - \sin\theta - 1 < 0$ を解け。
解答・解説
$2(1 - \sin^2\theta) - \sin\theta - 1 < 0 \ \Rightarrow \ (\sin\theta + 1)(2\sin\theta - 1) > 0$
$-1 \leqq \sin\theta \leqq 1$ より $\sin\theta > \frac{1}{2}$ であるため、
$$\mathbf{\frac{\pi}{6} < \theta < \frac{5}{6}\pi}$$
