数学Ⅰ_2次関数

平方完成・移動・最大最小・方程式・不等式・解の配置

キーボードの「→」キー、または画面下のボタンで進む仕様である。

1. 平方完成と平行移動・対称移動

関数の基本

2次関数のグラフの特徴（頂点と軸）を把握するため、基本形に変形する。

■ 一般形から標準形への平方完成

$$y = ax^2 + bx + c \ \implies \ \mathbf{y = a(x - p)^2 + q}$$ 頂点： $\mathbf{(p, q)}$ 、 軸： 直線 $\mathbf{x = p}$

■ 平行移動の公式（$x$軸方向 $p$、$y$軸方向 $q$）

$x \to x - p$ 、 $y \to y - q$ に置き換える。
対称移動のまとめ
・ $x$軸に関して対称 $\implies y \to -y$
・ $y$軸に関して対称 $\implies x \to -x$
・ 原点に関して対称 $\implies x \to -x, \ y \to -y$

2. 2次関数の最大・最小（軸の場合分け）

最重要テーマ

下に凸の放物線 $y = (x-a)^2 + q$ における定義域 $0 \leqq x \leqq 2$ での最小値の3パターン。

① $a < 0$ （軸が左外）：
定義域の左端 $x = 0$ で最小をとる。
② $0 \leqq a \leqq 2$ （軸が内側）：
頂点 $x = a$ で最小をとる（最小値 $q$）。
③ $a > 2$ （軸が右外）：
定義域の右端 $x = 2$ で最小をとる。
最大値・最小値の判別テクニック
最小値（下に凸）をとる点は、赤点で示した通り「グラフの最下点（頂点）」が定義域のグレーの帯に入っているかどうかでパッと見分けられます。

3. 2次方程式・不等式と判別式 D

グラフと視覚化

2次不等式の解は、グラフ $y = ax^2+bx+c$ と $x$軸の位置関係から捉える。

判別式 $D = b^2 - 4ac$ の符号による分類（$a > 0$）：
  • $D > 0$： $x$軸と異なる2点で交わる（$\alpha, \beta$） $$ax^2+bx+c < 0 \iff \mathbf{\alpha < x < \beta}$$ $$ax^2+bx+c > 0 \iff \mathbf{x < \alpha, \ \beta < x}$$
  • $D = 0$： 接する $\implies (x-\alpha)^2 \leqq 0$ 等
  • $D < 0$： 浮いている $\implies$ すべての実数／解なし
常に不等式が成り立つ条件（絶対不等式）
すべての実数 $x$ で $ax^2 + bx + c > 0$ が成立する条件 $\iff \mathbf{a > 0 \ \text{かつ} \ D < 0}$ （上に開いて浮いている状態）

4. 2次方程式の解の配置問題

応用・頻出

2次方程式 $f(x) = 0$ の解が指定された範囲にある条件は3つの視点で絞り込む。

■ 解の配置を絞り込む 3大条件（「D・軸・端点」）

  1. 判別式 $D$： 解が存在するか（実数解条件 $D \geqq 0$ や $D > 0$）
  2. 軸の位置： グラフの軸 $x = -\frac{b}{2a}$ が指定範囲のどこにあるか
  3. 端点での $y$ の値（境界値 $f(k)$）： 境界 $x = k$ における $f(k)$ の正負
例：「2解がともに k より大きい」条件
① $D \geqq 0$ 、 ② 軸 $> k$ 、 ③ $f(k) > 0$ の 3つの共通範囲（かつ） を求める。

演習問題［1］：頂点と平行移動

基本レベル
【問題】
放物線 $y = 2x^2 - 8x + 5$ の頂点の座標を求めよ。また、この放物線を $x$軸方向に $3$、$y$軸方向に $-2$ だけ平行移動した放物線の方程式を求めよ。
解答・解説
■ 平方完成：
$y = 2(x^2 - 4x) + 5 = 2(x - 2)^2 - 8 + 5 = 2(x - 2)^2 - 3$
よって、頂点の座標は $\mathbf{(2, -3)}$

■ 平行移動：
移動後の頂点は $(2+3, \ -3-2) = (5, -5)$ となる。
$x^2$ の係数 $2$ は変化しないため、求める方程式は：
$$y = 2(x - 5)^2 - 5 \quad \left(\text{展開形: } \mathbf{y = 2x^2 - 20x + 45}\right)$$

演習問題［2］：軸が動く2次関数の最小値

標準・頻出
【問題】
$0 \leqq x \leqq 2$ における関数 $f(x) = (x - a)^2 + 1$ の最小値を $a$ の値で場合分けして求めよ。
解答・解説
下に凸で軸は $x = a$。定義域 $0 \leqq x \leqq 2$ と軸の位置で3つに場合分けする。
① $a < 0$ のとき（軸が左外）：
$\quad x = 0$ で最小値をとる $\implies \mathbf{\text{最小値 } a^2 + 1 \quad (x=0)}$
② $0 \leqq a \leqq 2$ のとき（軸が内側）：
$\quad$ 頂点 $x = a$ で最小値をとる $\implies \mathbf{\text{最小値 } 1 \quad (x=a)}$
③ $a > 2$ のとき（軸が右外）：
$\quad x = 2$ で最小値をとる $\implies \mathbf{\text{最小値 } (2-a)^2 + 1 = a^2 - 4a + 5 \quad (x=2)}$

演習問題［3］：文字を含む2次不等式

標準レベル
【問題】
$x$ についての不等式 $x^2 - (a + 2)x + 2a < 0$ を解け。
解答・解説
因数分解すると $(x - 2)(x - a) < 0$ となる。
2つの境界値 $2$ と $a$ の大小関係で場合分けする。
① $a < 2$ のとき： $\mathbf{a < x < 2}$
② $a = 2$ のとき： $(x - 2)^2 < 0$ となり、これを満たす実数は存在しない $\implies \mathbf{\text{解なし}}$
③ $a > 2$ のとき： $\mathbf{2 < x < a}$

演習問題［4］：解の配置（正の解2つ）

応用・最重要
【問題】
2次方程式 $x^2 - 2mx + m + 6 = 0$ が、異なる2つの正の解をもつような定数 $m$ の値の範囲を求めよ。
解答・解説
$f(x) = x^2 - 2mx + m + 6$ とおく。軸は $x = m$。
「異なる2つの正の解」をもつ条件は、次の3条件が同時に成り立つこと：
① 判別式： $D/4 = (-m)^2 - (m + 6) > 0 \implies m^2 - m - 6 > 0 \implies (m-3)(m+2) > 0$
$\quad \implies m < -2, \ 3 < m \ \cdots \text{①'}$
② 軸の位置： 軸 $m > 0 \ \cdots \text{②'}$
③ 端点（$y$切片）： $f(0) = m + 6 > 0 \implies m > -6 \ \cdots \text{③'}$
①', ②', ③' の共通範囲を求めると、 $\mathbf{3 < m}$

2次関数のまとめ

総括
  1. 平方完成： 頂点 $(p, q)$ と軸 $x=p$ を掴むことが全てのスタート。
  2. 最大・最小： 軸が定義域の「内か外か（最小）」「中央より左右どちらか（最大）」で場合分け。
  3. 2次不等式： 式の形だけでなく、常にグラフと $x$軸の交わり（判別式 $D$）を視覚化する。
  4. 解の配置： 「$D$ の符号」「軸の位置」「端点 $f(k)$ の符号」の3セットで攻める。
学習のアドバイス
2次関数は数Ⅰ・数Ⅱ・数Ⅲすべての土台となる単元です。数式だけで処理しようとせず、常に簡単なグラフの概形を描いて考える癖をつけましょう。
