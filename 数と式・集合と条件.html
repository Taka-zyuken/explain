1. 展開・因数分解の極意

数と式

複雑な多項式は「置き換え」と「最低次数の文字での整理」が鉄則。

■ 最低次数の文字について整理する手順

2つ以上の文字を含む式は、最も次数が低い文字に着目して降順に整理する。
例： $x^2 + xy - 2y^2 + 3x + 3y + 2$ （$x, y$ ともに2次 $\to$ $x$ で整理）
$$= x^2 + (y + 3)x - (2y^2 - 3y - 2) = x^2 + (y + 3)x - (2y + 1)(y - 2)$$ たすき掛けにより $\mathbf{(x + 2y + 1)(x - y + 2)}$ と因数分解できる。
3次の因数分解公式（数学Ⅰ発展）
・ $a^3 + b^3 = (a + b)(a^2 - ab + b^2)$
・ $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$

2. 実数と絶対値記号の外し方

数の性質

絶対値 $|a|$ は「原点からの距離」を表し、中身の正負で場合分けして外す。

$$\mathbf{|a| = \begin{cases} a & (a \geqq 0 \text{ のとき}) \\ -a & (a < 0 \text{ のとき}) \end{cases}}$$

⚠️ 最重要注意点：

$\sqrt{a^2} = |a|$ である。（単に $a$ としない！）
例： $\sqrt{(-3)^2} = |-3| = 3$
1次不等式の方針
$|x| < k \iff -k < x < k$ 、 $|x| > k \iff x < -k, \ k < x$ と瞬時に変換できる。

3. 集合とド・モルガンの法則

論理の基礎

範囲や集まりを視覚的に表現するベン図と、補集合の基本法則。

  • 共通部分 $A \cap B$： かつ（両方に入る）
  • 和集合 $A \cup B$： または（少なくとも一方）
  • ド・モルガンの法則： $$\overline{A \cup B} = \overline{A} \cap \overline{B}, \quad \overline{A \cap B} = \overline{A} \cup \overline{B}$$ （バーを千切ると記号 $\cap, \cup$ が逆転する！）
個数定理
$n(A \cup B) = n(A) + n(B) - n(A \cap B)$ （重なっている部分を1回引く）

4. 命題と必要十分条件

最重要概念

命題 $p \implies q$ の真偽と、矢印の向きによる条件の判定。

■ 必要条件・十分条件の見分け方（矢印フロー）

$$p \ \overset{\text{主語から出る}}{\underset{\text{十分条件}}{\Longrightarrow}} \ q \ \overset{\text{主語に入る}}{\underset{\text{必要条件}}{\Longrightarrow}} \ p$$
  • $p \implies q$ が真 $\iff$ $p$ は
    $q$ であるための十分条件
  • $q \implies p$ が真 $\iff$ $p$ は
    $q$ であるための必要条件
  • 双方が真 $\iff$ 必要十分条件
    （同値：$p \iff q$）

「$p \implies q$」と「$q \implies p$」の矢印の真偽をそれぞれ確認するのが判定の鉄則。

■ 例題1： $p: x = 2$ と $q: x^2 = 4$

① $p \implies q$ （$x = 2 \implies x^2 = 4$）：
$\quad x = 2$ ならば確実に $x^2 = 4$ になるので 【真】 （$\to$ 十分条件を満たす）
② $q \implies p$ （$x^2 = 4 \implies x = 2$）：
$\quad x = -2$ の可能性（反例）があるため 【偽】 （$\to$ 必要条件を満たさない）
結論： $x = 2$ は $x^2 = 4$ であるための 「十分条件であるが必要条件でない」

💡 日常の例（集合の大きさイメージ）： 「東京にいる」と「日本にいる」

・ 東京にいるなら $\implies$ 日本にいる： 絶対に成り立つ（十分）
・ 日本にいるなら $\implies$ 東京にいる： 大阪や北海道かも（偽・成り立たない）
$\to$ 狭い範囲（東京） は 広い範囲（日本） に入るための 「十分条件」！
$\to$ 広い範囲（日本） は 狭い範囲（東京） に入るための 「必要条件」！
判別の3ステップ
1. 主語を確認する（「〜は、…であるための」の「〜は」の部分）
2. 「主語 $\implies$ 相手」の真偽チェック $\to$ 真なら十分条件（主語から矢印が出る）
3. 「相手 $\implies$ 主語」の真偽チェック $\to$ 真なら必要条件（主語に矢印が入る）
集合の包含関係との連動
条件 $p, q$ を満たす集合を $P, Q$ とすると、命題 $p \implies q$ が真であることは $P \subset Q$（$P$ が $Q$ にすっぽり包まれる）と同値である。

5. 逆・裏・対偶と背理法

証明の技法

命題の変形と、証明が難しい場合の迂回証明アプローチ。

■ 四角関係（逆・裏・対偶）

・ 命題 $p \implies q$ の逆： $q \implies p$
・ 命題 $p \implies q$ の裏： $\overline{p} \implies \overline{q}$
・ 命題 $p \implies q$ の対偶： $\mathbf{\overline{q} \implies \overline{p}}$

★ 最重要原理：元命題とその対偶の真偽は完全に一致する！

背理法の基本ステップ
1. 結論の否定（「〜でない」と仮定）を仮定する。
2. 矛盾（矛盾・与えられた条件との食い違い）を導き出す。
3. したがって元の結論が正しいと主張する。（例：$\sqrt{2}$ が無理数であることの証明）

演習問題［1］：複雑な因数分解

基本演習
【問題】
次の式を因数分解せよ。
$$a(b^2 - c^2) + b(c^2 - a^2) + c(a^2 - b^2)$$
解答・解説
どの文字（$a, b, c$）についても2次なので、$a$ について降順に整理する。
与式 $= (c - b)a^2 + (b^2 - c^2)a + (bc^2 - b^2c)$
$= -(b - c)a^2 + (b - c)(b + c)a - bc(b - c)$
共通因数 $(b - c)$ で括り出す：
$= (b - c) \big( -a^2 + (b + c)a - bc \big) = -(b - c) \big( a^2 - (b + c)a + bc \big)$
$= -(b - c)(a - b)(a - c) = \mathbf{(a - b)(b - c)(c - a)}$ （輪環の順に整理）

演習問題［2］：絶対値と場合分け

標準演習
【問題】
方程式 $|x - 2| + |x + 1| = 5$ を解け。
解答・解説
中身が $0$ になる境界 $x = -1, 2$ で3つの区間に場合分けする。
① $x < -1$ のとき： 両方マイナスで外れる
$\quad -(x - 2) - (x + 1) = 5 \implies -2x + 1 = 5 \implies x = -2$ （$x < -1$ を満たす）
② $-1 \leqq x < 2$ のとき： 前マイナス・後プラス
$\quad -(x - 2) + (x + 1) = 5 \implies 3 = 5$ （不能・解なし）
③ $x \geqq 2$ のとき： 両方プラスで外れる
$\quad (x - 2) + (x + 1) = 5 \implies 2x - 1 = 5 \implies x = 3$ （$x \geqq 2$ を満たす）
以上より、求める解は $\mathbf{x = -2, \ 3}$

演習問題［3］：必要十分条件の判定

頻出演習
【問題】
$x, y$ を実数とするとき、$x^2 + y^2 = 0$ は $x = 0$ かつ $y = 0$ であるための何条件か。
（必要十分条件／必要条件であるが十分条件でない／十分条件であるが必要条件でない／いずれでもない）
解答・解説
条件 $p: x^2 + y^2 = 0$ 、 条件 $q: x = 0 \text{ かつ } y = 0$ とする。
・ $p \implies q$ の検証：
$\quad x, y$ は実数なので $x^2 \geqq 0, y^2 \geqq 0$。足して $0$ になるには $x^2 = 0$ かつ $y^2 = 0$ しかない。
$\quad$ よって $x = 0$ かつ $y = 0$ となり、真（十分条件を満たす）。
・ $q \implies p$ の検証：
$\quad x = 0, y = 0$ のとき $0^2 + 0^2 = 0$ となり、真（必要条件を満たす）。
双方ともに真であるため、正解は 必要十分条件 である。

演習問題［4］：背理法を用いた証明

応用演習
【問題】
$\sqrt{2}$ が無理数であることを用いて、 $1 + \sqrt{2}$ は無理数であることを証明せよ。
解答・解説
【証明】
$1 + \sqrt{2}$ が有理数であると仮定し、それを $r$（有理数）とおく。
$$1 + \sqrt{2} = r \ \implies \ \sqrt{2} = r - 1$$ ここで、$r$ は有理数なので $r - 1$ も有理数である。
しかし、この等式は左辺の $\sqrt{2}$ が無理数であることに矛盾する。
したがって、最初の仮定「$1 + \sqrt{2}$ が有理数である」は誤りであり、
$1 + \sqrt{2}$ は 無理数である。 $\quad \blacksquare$
