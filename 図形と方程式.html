数学Ⅱ_図形と方程式・軌跡と領域

初学者用

キーボードの「→」キー、または画面下のボタンで進む仕様である。

1. 2点間の距離・分点座標

平面上の座標

座標平面上の 2 点 $\text{A}(x_1, y_1), \text{B}(x_2, y_2)$ に対する基本公式。

■ 2点間の距離 AB

$$\text{AB} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

■ 線分 AB を $m : n$ に分ける点 P の座標

$$\text{内分点：} \left( \frac{nx_1 + mx_2}{m+n}, \, \frac{ny_1 + my_2}{m+n} \right)$$ $$\text{外分点：} \left( \frac{-nx_1 + mx_2}{m-n}, \, \frac{-ny_1 + my_2}{m-n} \right) \quad (\text{※ } n \text{ を } -n \text{ に置換})$$
内分点： $\left( \frac{nx_1 + mx_2}{m+n}, \, \frac{ny_1 + my_2}{m+n} \right)$
外分点： $\left( \frac{-nx_1 + mx_2}{m-n}, \, \frac{-ny_1 + my_2}{m-n} \right)$ （※ $n$ を $-n$ に置換）
重心の座標
$\triangle\text{ABC}$ の重心 $\text{G}$ の座標は、3頂点の平均 $\left( \frac{x_1+x_2+x_3}{3}, \frac{y_1+y_2+y_3}{3} \right)$ である。

2. 直線の方程式

直線の決定

直線は「通過する1点と傾き」または「通過する2点」で一意に定まる。

■ 1点 $(x_1, y_1)$ を通り、傾き $m$ の直線

$$y - y_1 = m(x - x_1)$$

■ 異なる 2 点 $(x_1, y_1), (x_2, y_2)$ を通る直線 ($x_1 \neq x_2$)

$$y - y_1 = \frac{y_2 - y_1}{x_2 - x_1} (x - x_1)$$

3. 2直線の平行条件・垂直条件

位置関係

2直線 $l_1: y = m_1 x + k_1$, $l_2: y = m_2 x + k_2$ についての重要な位置関係。

  • 平行条件： 傾きが等しい $$m_1 = m_2$$
  • 垂直条件： 傾きの積が $-1$ $$m_1 \cdot m_2 = -1$$
一般形 $ax + by + c = 0$ の場合
・平行：$a_1 b_2 - a_2 b_1 = 0$
・垂直：$a_1 a_2 + b_1 b_2 = 0$

4. 点と直線の距離の公式と証明

最重要公式

点 $\text{P}(x_1, y_1)$ と直線 $l: ax + by + c = 0$ の距離 $d$ を求める公式。

$$d = \frac{|a x_1 + b y_1 + c|}{\sqrt{a^2 + b^2}}$$

【証明】（$a \neq 0, b \neq 0$ のとき）

点 $\text{P}(x_1, y_1)$ から直線 $l$ に下ろした垂線の足を $\text{H}(x_0, y_0)$ とおくと、距離 $d = \text{PH}$ である。
直線 $\text{PH}$ は $l$ に垂直なので、その傾きは $\frac{b}{a}$ と表せる。したがって、実数 $k$ を用いて：

$$x_1 - x_0 = ak \quad \implies \quad x_0 = x_1 - ak$$ $$y_1 - y_0 = bk \quad \implies \quad y_0 = y_1 - bk$$

点 $\text{H}(x_0, y_0)$ は直線 $ax + by + c = 0$ 上にあるため代入すると：
$a(x_1 - ak) + b(y_1 - bk) + c = 0 \quad \implies \quad (a^2 + b^2)k = ax_1 + by_1 + c$
よって、 $k = \frac{ax_1 + by_1 + c}{a^2 + b^2}$ となる。

求める距離 $d = \text{PH} = \sqrt{(x_1 - x_0)^2 + (y_1 - y_0)^2} = \sqrt{(ak)^2 + (bk)^2} = \sqrt{a^2 + b^2}|k|$ より、
代入すると： $\mathbf{d = \sqrt{a^2 + b^2} \cdot \frac{|ax_1 + by_1 + c|}{a^2 + b^2} = \frac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}}$ $\quad \blacksquare$

5. 円の方程式（標準形・一般形）

円の定義

平面上で、定点からの距離（半径 $r$）が一定である点の集合。

■ 標準形（中心 $(a, b)$、半径 $r$）

$$(x - a)^2 + (y - b)^2 = r^2$$

■ 一般形

$$x^2 + y^2 + Lx + My + N = 0$$
一般形から標準形へ
一般形で与えられた場合は、$x, y$ それぞれについて平方完成を行うことで中心座標と半径を求める。

6. 円と直線の位置関係

判別式・dとrの比較

円の中心と直線の距離 $d$、および円の半径 $r$ の大小関係で分類する。

  • $d < r$ ： 2点で交わる（交点2個）
  • $d = r$ ： 接する（共有点1個・接線）
  • $d > r$ ： 離れている（共有点なし）
解法の選択
連立して判別式 $D$ を使う方法もあるが、「点と直線の距離 $d$ と半径 $r$ の比較」の方が計算が圧倒的に楽になることが多い。

7. 円上の点における接線

公式

原点を中心とする円 $x^2 + y^2 = r^2$ 上の点 $(x_1, y_1)$ における接線の方程式。

$$x_1 x + y_1 y = r^2$$
中心が $(a, b)$ の場合
$(x - a)^2 + (y - b)^2 = r^2$ 上の点 $(x_1, y_1)$ における接線は、$(x_1 - a)(x - a) + (y_1 - b)(y - b) = r^2$ となる。

8. 軌跡の求め方手順

解法手順

与えられた条件を満たして動く点 $\text{P}$ が描く図形（軌跡）を求める手順。

  1. Step 1： 軌跡を求めたい点 $\text{P}$ の座標を $(x, y)$ と置く。
  2. Step 2： 与えられた図形的な条件を $x, y$ の関係式で表す。
  3. Step 3： 式を整理して、知っている図形（直線・円など）の方程式を導く。
  4. Step 4【除外点】： 除外すべき点や変域の制限がないか確認し、「逆に…」と書いて十分性を述べる。

9. 不等式の表す領域

領域の視覚化

不等式の解の集合を座標平面上のエリア（領域）として視覚化する。

■ 直線 $y = mx + n$ の領域

  • ・ $y > mx + n \ \Rightarrow \ $ 直線より上側
  • ・ $y < mx + n \ \Rightarrow \ $ 直線より下側

■ 円 $(x - a)^2 + (y - b)^2 = r^2$ の領域

  • ・ $(x - a)^2 + (y - b)^2 < r^2 \ \Rightarrow \ $ 円の内部
  • ・ $(x - a)^2 + (y - b)^2 > r^2 \ \Rightarrow \ $ 円の外部
境界線の扱い
等号を含む（$\leqq, \geqq$）ならば「境界線を含む」、含まない（$<, >$）ならば「境界線を含まない」と必ず明記する。

10. 領域と最大・最小（線形計画法）

応用パターン

条件を満たす領域内で $x + y$ や $ax + by$ の最大値・最小値を求める手法。

  1. Step 1： 与えられた条件不等式が表す領域 $D$ を図示する。
  2. Step 2： 最大・最小を求めたい式を $= k$ と置く
    （例: $x + y = k \Rightarrow y = -x + k$）
  3. Step 3： 直線 $y = -x + k$ が領域 $D$ と共有点をもちながら動くとき、$y$ 切片 $k$ が最大・最小となる位置を判定する。

演習問題［1］：分点と重心

基本演習
【問題】
2点 $\text{A}(1, -2), \text{B}(7, 4)$ を結ぶ線分 $\text{AB}$ を $2 : 1$ に内分する点 $\text{P}$、および外分する点 $\text{Q}$ の座標を求めよ。
解答・解説
内分点 $\text{P}$：$\left( \frac{1 \cdot 1 + 2 \cdot 7}{2+1}, \, \frac{1 \cdot (-2) + 2 \cdot 4}{2+1} \right) = \left( \frac{15}{3}, \, \frac{6}{3} \right) = \mathbf{(5, 2)}$
外分点 $\text{Q}$：$\left( \frac{-1 \cdot 1 + 2 \cdot 7}{2-1}, \, \frac{-1 \cdot (-2) + 2 \cdot 4}{2-1} \right) = \left( \frac{13}{1}, \, \frac{10}{1} \right) = \mathbf{(13, 10)}$

演習問題［2］：平行・垂直な直線

標準演習
【問題】
点 $(2, 3)$ を通り、直線 $2x - 3y + 6 = 0$ に (1) 平行な直線、(2) 垂直な直線の方程式を求めよ。
解答・解説
元の直線の傾きは $\frac{2}{3}$ である。
(1) 平行な直線：傾き $\frac{2}{3}$ で点 $(2, 3)$ を通るので、
$y - 3 = \frac{2}{3}(x - 2) \quad \Rightarrow \quad \mathbf{2x - 3y + 5 = 0}$
(2) 垂直な直線：傾き $m$ は $\frac{2}{3} \cdot m = -1 \Rightarrow m = -\frac{3}{2}$。
$y - 3 = -\frac{3}{2}(x - 2) \quad \Rightarrow \quad \mathbf{3x + 2y - 12 = 0}$

演習問題［3］：点と直線の距離

基本演習
【問題】
原点 $(0, 0)$ と直線 $3x + 4y - 10 = 0$ の距離 $d$ を求めよ。
解答・解説
点と直線の距離の公式を適用して： $$d = \frac{|3 \cdot 0 + 4 \cdot 0 - 10|}{\sqrt{3^2 + 4^2}} = \frac{|-10|}{\sqrt{9 + 16}} = \frac{10}{\sqrt{25}} = \frac{10}{5} = \mathbf{2}$$

演習問題［4］：円と直線の関係（dとr）

標準演習
【問題】
円 $x^2 + y^2 = 5$ と直線 $y = 2x + k$ が接するとき、定数 $k$ の値を求めよ。
解答・解説
円の中心 $(0,0)$、半径 $r = \sqrt{5}$。直線の式を変形すると $2x - y + k = 0$。
中心と直線の距離 $d$ が半径 $r$ に等しくなればよいので： $$d = \frac{|2\cdot 0 - 0 + k|}{\sqrt{2^2 + (-1)^2}} = \frac{|k|}{\sqrt{5}}$$ $d = r$ より $\frac{|k|}{\sqrt{5}} = \sqrt{5} \ \Rightarrow \ |k| = 5 \ \Rightarrow \ \mathbf{k = \pm 5}$

演習問題［5］：軌跡の方程式

応用演習
【問題】
2点 $\text{A}(-2, 0), \text{B}(4, 0)$ に対して、$\text{AP} : \text{BP} = 2 : 1$ を満たす点 $\text{P}$ の軌跡を求めよ。（アポロニウスの円）
解答・解説
点 $\text{P}$ の座標を $(x, y)$ と置く。 $\text{AP} : \text{BP} = 2 : 1 \ \Rightarrow \ \text{AP} = 2\text{BP} \ \Rightarrow \ \text{AP}^2 = 4\text{BP}^2$
$$(x + 2)^2 + y^2 = 4 \{ (x - 4)^2 + y^2 \}$$ 展開して整理すると： $3x^2 - 36x + 3y^2 + 60 = 0 \ \Rightarrow \ x^2 - 12x + y^2 + 20 = 0$
平方完成して： $\mathbf{(x - 6)^2 + y^2 = 16}$ （中心 $(6, 0)$、半径 $4$ の円）

演習問題［6］：領域における最大・最小

標準演習
【問題】
$x, y$ が 4つの不等式 $x \geqq 0, \ y \geqq 0, \ x + 2y \leqq 8, \ 2x + y \leqq 7$ を同時に満たすとき、$x + y$ の最大値および最小値を求めよ。
解答・解説
与えられた不等式の表す領域 $D$ は、4点 $(0, 0), (3.5, 0), (2, 3), (0, 4)$ を頂点とする四角形の周および内部である。
$x + y = k$ と置くと、$y = -x + k$ は傾き $-1$、 $y$ 切片 $k$ の直線を表す。
この直線が領域 $D$ と共地点をもつときの $k$ の値を考えると：
・ 最大値：直線が点 $(2, 3)$ を通るとき、 $\mathbf{\text{最大値 } 5 \quad (x=2, y=3)}$
・ 最小値：直線が原点 $(0, 0)$ を通るとき、 $\mathbf{\text{最小値 } 0 \quad (x=0, y=0)}$

演習問題［7］：中点の軌跡

応用演習
【問題】
点 $\text{Q}$ が円 $x^2 + y^2 = 4$ 上を動くとき、点 $\text{A}(4, 0)$ と点 $\text{Q}$ を結ぶ線分 $\text{AQ}$ の中点 $\text{P}$ の軌跡を求めよ。
解答・解説
点 $\text{Q}$ の座標を $(s, t)$、点 $\text{P}$ の座標を $(x, y)$ と置く。
点 $\text{Q}$ は円上にあるため、$s^2 + t^2 = 4 \ \cdots \text{①}$
点 $\text{P}$ は線分 $\text{AQ}$ の中点なので、 $x = \frac{s + 4}{2}, \ y = \frac{t + 0}{2}$
これを $s, t$ について解くと： $s = 2x - 4, \ t = 2y$
これらを①式に代入すると： $(2x - 4)^2 + (2y)^2 = 4 \ \implies \ 4(x - 2)^2 + 4y^2 = 4$
両辺を $4$ で割ると、 $\mathbf{(x - 2)^2 + y^2 = 1}$
したがって、求める軌跡は 中心 $(2, 0)$、半径 $1$ の円 である。
