数学Ⅰ_データの分析

代表値・四分位数・箱ひげ図・分散・標準偏差・共分散・相関係数

キーボードの「→」キー、または画面下のボタンで進む仕様である。

1. 代表値と四分位数・箱ひげ図

位置と散らばり

データ全体の特徴を表す「代表値」と、散らばり具合を可視化する「四分位数」。

  • 平均値 ($\bar{x}$) / 中央値 (メジアン) / 最頻値 (モード)
  • 四分位数： データを小さい順に並べ 4等分 する位置の数値。
    ・ 第1四分位数 ($Q_1$)、中央値 ($Q_2$)、第3四分位数 ($Q_3$)
    ・ 四分位範囲 (IQR)： $Q_3 - Q_1$
    ・ 四分位偏差： $\frac{Q_3 - Q_1}{2}$
箱ひげ図の注意点
箱ひげ図の「箱」の中に全データの約50%が含まれ、「各区間（最小〜$Q_1$など）」にそれぞれ全体の約25%のデータ個数が含まれる。

2. 分散と標準偏差

偏差の2乗平均

平均値からのズレ（偏差）を用いて、データ全体の散らばりを数値化する。

■ 分散 $s^2$ （偏差の2乗の平均）

$$s^2 = \frac{1}{n} \sum_{i=1}^n (x_i - \bar{x})^2 = \mathbf{\overline{x^2} - (\bar{x})^2} \quad \text{（「2乗の平均」$-$「平均の2乗」）}$$

■ 標準偏差 $s$ （単位を元データに揃えた値）

$$s = \sqrt{s^2} = \sqrt{\frac{1}{n} \sum_{i=1}^n (x_i - \bar{x})^2}$$
データの変換と指標の変化
データ $x_i$ を $y_i = a x_i + b$ と変換した場合：
・ 平均値： $\bar{y} = a\bar{x} + b$
・ 分 散： $s_y^2 = a^2 s_x^2$
・ 標準偏差： $s_y = |a| s_x$ （$+b$ の平行移動は散らばり幅に影響しない）

平均値からのズレ（偏差）を用いて、データ全体の散らばりを数値化する。

💡 具体数値検証1： データ $x = \{1, \ 3, \ 5\}$ （個数 $n = 3$）

・ 平均： $\bar{x} = \frac{1 + 3 + 5}{3} = \mathbf{3}$
・ 定義式で計算： $s_x^2 = \frac{(1-3)^2 + (3-3)^2 + (5-3)^2}{3} = \frac{4 + 0 + 4}{3} = \mathbf{\frac{8}{3}}$
・ 公式で計算： 2乗の平均 $\overline{x^2} = \frac{1^2 + 3^2 + 5^2}{3} = \frac{35}{3} \implies s_x^2 = \frac{35}{3} - 3^2 = \frac{35}{3} - \frac{27}{3} = \mathbf{\frac{8}{3}}$ （完全一致！）

💡 具体数値検証2： 新データ $\mathbf{y = 2x + 10}$ としたとき（$y = \{12, \ 16, \ 20\}$）

・ 平均値： $\bar{y} = \frac{12 + 16 + 20}{3} = \mathbf{16}$ $\quad \left(\text{公式: } 2\bar{x} + 10 = 2 \times 3 + 10 = \mathbf{16}\right)$
・ 分 散： $s_y^2 = \frac{(12-16)^2 + (16-16)^2 + (20-16)^2}{3} = \frac{16 + 0 + 16}{3} = \mathbf{\frac{32}{3}}$ $\quad \left(\text{公式: } 2^{\mathbf{2}} s_x^2 = 4 \times \frac{8}{3} = \mathbf{\frac{32}{3}}\right)$
・ 標準偏差： $s_y = \sqrt{\frac{32}{3}} = 2 \cdot \sqrt{\frac{8}{3}} = \mathbf{2 s_x}$ （$+10$ してもデータ同士の間隔は一切広がらない）
指標の変化ルールのポイント
全体を一律 $+10$ してもデータ同士の相対的なズレ（散らばり）は変化しないため、$b$ は分散・標準偏差に影響しません。一方、全体を $a$ 倍 するとデータ間隔も $a$ 倍になるため、標準偏差は $|a|$ 倍、分散（2乗）は $a^2$ 倍 に拡大・変換されます。

3. 共分散と相関係数（正方形散布図）

2変数の相関

2つのデータ $x, y$ の直線的な関係（正の相関・負の相関）の強さを表す指標。

■ 共分散 $s_{xy}$ と相関係数 $r$ の公式

$$s_{xy} = \frac{1}{n} \sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y}) = \overline{xy} - \bar{x}\bar{y}, \qquad r = \frac{s_{xy}}{s_x s_y} = \frac{\text{共分散}}{\text{xの標準偏差} \times \text{yの標準偏差}}$$
相関係数 r の値: 0.80
相関係数 r の視覚的変化ルール
・ $r = 1.00$（強い正の相関）： 点が右上がりの $45^\circ$ 直線上に綺麗に並ぶ。
・ $r = 0.00$（相関なし）： 正方形の範囲内にランダム（円状）にバラついて直線傾向が消える。
・ $r = -1.00$（強い負の相関）： 点が右下がりの $45^\circ$ 直線上に綺麗に並ぶ。

演習問題［1］：四分位数と範囲

基本レベル
【問題】
次の 9 個のデータがある。
$$3, \ 5, \ 6, \ 8, \ 10, \ 12, \ 14, \ 15, \ 18$$ (1) 第1四分位数 $Q_1$、中央値 $Q_2$、第3四分位数 $Q_3$ を求めよ。
(2) 四分位範囲および四分位偏差を求めよ。
解答・解説
(1) 各四分位数の求め方：
データ数は 9（奇数）なので、中央値 $Q_2$ は 5番目の数値 $\mathbf{Q_2 = 10}$。
・ 下位グループ ($3, 5, 6, 8$) の中央値 $\implies Q_1 = \frac{5+6}{2} = \mathbf{5.5}$
・ 上位グループ ($12, 14, 15, 18$) の中央値 $\implies Q_3 = \frac{14+15}{2} = \mathbf{14.5}$

(2) 四分位範囲と偏差：
・ 四分位範囲： $Q_3 - Q_1 = 14.5 - 5.5 = \mathbf{9}$
・ 四分位偏差： $\frac{9}{2} = \mathbf{4.5}$

演習問題［2］：分散と標準偏差

標準レベル
【問題】
5個のデータ $2, \ 4, \ 5, \ 6, \ 8$ について、平均値 $\bar{x}$、分散 $s^2$、標準偏差 $s$ を求めよ。
解答・解説
・ 平均値： $\bar{x} = \frac{2 + 4 + 5 + 6 + 8}{5} = \frac{25}{5} = \mathbf{5}$

・ 分散（定義通り）：
$s^2 = \frac{(2-5)^2 + (4-5)^2 + (5-5)^2 + (6-5)^2 + (8-5)^2}{5} = \frac{9 + 1 + 0 + 1 + 9}{5} = \frac{20}{5} = \mathbf{4}$

・ 標準偏差： $s = \sqrt{4} = \mathbf{2}$

演習問題［3］：データの変換と指標

標準・頻出
【問題】
データ $x$ の平均値が $\bar{x} = 50$、標準偏差が $s_x = 10$ であるとき、
新しいデータ $y = 1.2 x + 5$ の平均値 $\bar{y}$ および標準偏差 $s_y$ を求めよ。
解答・解説
変数の一次変換公式 $y = ax + b$ を適用する。

・ 平均値：
$$\bar{y} = 1.2 \bar{x} + 5 = 1.2 \times 50 + 5 = 60 + 5 = \mathbf{65}$$ ・ 標準偏差：
$$s_y = |1.2| s_x = 1.2 \times 10 = \mathbf{12}$$ （※ 定数 $+5$ は各データを平行移動させるだけなので、データの散らばり具合（標準偏差）には影響しない）

演習問題［4］：相関係数の算出

応用・最重要
【問題】
2つのデータ $x, y$ について、それぞれの分散が $s_x^2 = 16, \ s_y^2 = 25$ であり、共分散が $s_{xy} = 12$ であった。このとき相関係数 $r$ を求めよ。
解答・解説
まず各データの標準偏差を求める。
・ $x$ の標準偏差： $s_x = \sqrt{16} = 4$
・ $y$ の標準偏差： $s_y = \sqrt{25} = 5$

相関係数の定義式 $r = \frac{s_{xy}}{s_x s_y}$ に代入して：
$$r = \frac{12}{4 \times 5} = \frac{12}{20} = \mathbf{0.6}$$ （※ 正の値であり、$0.6$ なので「やや強い正の相関」があると言える）

データ修正時の計算テクニック

共通テスト対策

誤った入力値を後から訂正する場合、「和」と「2乗の和」の変化に着目する。

■ 修正の手順（$x_{old} \to x_{new}$）

  1. 新しい合計（和）： $\text{Sum}_{new} = \text{Sum}_{old} - x_{old} + x_{new} \implies$ 新平均 $\bar{x}_{new}$
  2. 新しい2乗の和： $\text{SumSq}_{new} = \text{SumSq}_{old} - x_{old}^2 + x_{new}^2$
  3. 新分散： $s_{new}^2 = \frac{\text{SumSq}_{new}}{n} - (\bar{x}_{new})^2$ で計算
計算のポイント
偏差 $(x - \bar{x})$ の表を一から作り直すと計算が極めて煩雑になるため、必ず **「2乗の和の修正」 $\to$ 「公式 $\overline{x^2} - (\bar{x})^2$」** のルートで計算する。

データの分析のまとめ

総括
  1. 四分位数・箱ひげ図： データを4分割する位置とデータの割合（約25%ずつ）を掴む。
  2. 分散・標準偏差： $s^2 = \overline{x^2} - (\bar{x})^2$ の公式を素早く使いこなす。
  3. 共分散・相関係数： $r = \frac{s_{xy}}{s_x s_y}$ で散布図の直線的傾向を判定する（$-1 \leqq r \leqq 1$）。
  4. 一次変換： $y = ax+b$ において、標準偏差は $|a|$ 倍され、定数 $b$ は影響しない。
学習のアドバイス
「データの分析」は、定義式や計算公式がやや複雑に見えますが、「和」と「2乗の和」さえ正しく集計できれば確実に得点できる単元です。正直二次で利用する大学は慶應薬学程度ですので、共通テスト等での表や散布図の読み取りに慣れておきましょう。
