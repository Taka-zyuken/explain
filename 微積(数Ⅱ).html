数学Ⅱ_微分法・積分法

初学者用

キーボードの「→」キー、または画面下のボタンで進む仕様である。

1. 平均変化率と微分係数

極限の概念

関数の変化の割合から、瞬間的な変化の割合（接線の傾き）を導出する。

■ 平均変化率（2点を通る割線の傾き）

$$\frac{\Delta y}{\Delta x} = \frac{f(a+h) - f(a)}{h}$$

■ 微分係数 $f'(a)$ （点 $a$ での接線の傾き）

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$
まとめ
微分係数 $f'(a)$ は、曲線 $y = f(x)$ 上の点 $(a, f(a))$ における接線の傾きを表す。

2. 導関数と微分の計算

基本公式

関数 $f(x)$ から導関数 $f'(x)$ を求める操作を微分するという。

■ 導関数の公式

$$(x^n)' = n x^{n-1} \quad (n = 1, 2, 3, \dots)$$ $$(c)' = 0 \quad (c \text{ は定数})$$ $$\left\{ k \cdot f(x) + l \cdot g(x) \right\}' = k \cdot f'(x) + l \cdot g'(x)$$
計算例
$y = 3x^3 - 5x^2 + 4$ を微分すると、$y' = 3 \cdot (3x^2) - 5 \cdot (2x) + 0 = \mathbf{9x^2 - 10x}$

3. 接線の方程式

標準解法

曲線 $y = f(x)$ 上の点 $(a, f(a))$ における接線の方程式は以下で与えられる。

$$y - f(a) = f'(a)(x - a)$$
ポイント
接線を作るには、① 接点の $x$ 座標 $a$、② 接点の $y$ 座標 $f(a)$、③ 接線の傾き $f'(a)$ の3つが必要である。

4. 関数の増減と極値（極大・極小）

グラフの描画

導関数 $f'(x)$ の符号（＋ / －）を調べることで、元の関数 $f(x)$ の増減がわかる。

  • $f'(x) > 0$ の区間 $\Rightarrow f(x)$ は増加（↗）
  • $f'(x) < 0$ の区間 $\Rightarrow f(x)$ は減少（↘）
  • $f'(x) = 0$ となる前後で符号が：
    • 正 $\to$ 負： 極大 となる
    • 負 $\to$ 正： 極小 となる

5. 増減表の書き方手順

手順の標準化

3次関数のグラフを描くための標準手順（4ステップ）である。

  1. Step 1： 導関数 $f'(x)$ を計算する。
  2. Step 2： $f'(x) = 0$ となる $x$ の値を求める。
  3. Step 3： 増減表を作成し、$f'(x)$ の符号（＋/－）と $f(x)$ の矢印（↗/↘）を記入する。
  4. Step 4： 極値および $y$ 切片を打ち、滑らかな曲線で結ぶ。

6. 不定積分

微分の逆演算

微分すると $f(x)$ になる関数 $F(x)$ を求める操作を積分するという。

$$\int f(x) \, dx = F(x) + C \quad (C \text{ は積分定数})$$

■ 不定積分の公式

$$\int x^n \, dx = \frac{1}{n+1} x^{n+1} + C \quad (n = 0, 1, 2, \dots)$$
$$\int k \, dx = kx + C \quad (k \text{ は定数})$$
注意
不定積分では、微分すると消えてしまう定数項を表す $+ C$（積分定数） を絶対に忘れないこと。

7. 定積分とその性質

基本公式

区間 $[a, b]$ を指定した積分を定積分と呼び、数値として算出される。

$$\int_{a}^{b} f(x) \, dx = \left[ F(x) \right]_{a}^{b} = F(b) - F(a)$$

■ 定積分の基本性質

$$\int_{a}^{a} f(x) \, dx = 0$$
$$\int_{b}^{a} f(x) \, dx = -\int_{a}^{b} f(x) \, dx$$
$$\int_{a}^{c} f(x) \, dx + \int_{c}^{b} f(x) \, dx = \int_{a}^{b} f(x) \, dx$$

8. 定積分と面積

面積計算

曲線と $x$ 軸で囲まれた部分の面積 $S$ は、定積分で求められる。

  • $f(x) \geqq 0$（軸の上側）のとき： $$S = \int_{a}^{b} f(x) \, dx$$
  • $f(x) \leqq 0$（軸の下側）のとき： $$S = -\int_{a}^{b} f(x) \, dx$$

9. 2曲線間の面積と $1/6$ 公式

裏ワザ・高速化

2つの曲線 $y = f(x)$ と $y = g(x)$（$f(x) \geqq g(x)$）で囲まれた面積は「上 － 下」で計算する。

■ 放物線と直線（または放物線）で囲まれた面積の $1/6$ 公式

$$\int_{\alpha}^{\beta} (x - \alpha)(x - \beta) \, dx = -\frac{1}{6}(\beta - \alpha)^3$$ $$\Rightarrow S = \frac{|a|}{6}(\beta - \alpha)^3$$

※ $\alpha, \beta$ は2曲線の交点の $x$ 座標（$\alpha < \beta$）、$a$ は2次式を引いたときの $x^2$ の係数。

時短テクニック
共通テストや記述試験での検算において、放物線で囲まれた面積は $1/6$ 公式を使うことで圧倒的に速く正確に計算できる。

1/6 公式の証明

計算公式の導出

$\int_{\alpha}^{\beta} (x - \alpha)(x - \beta) \, dx = -\frac{1}{6}(\beta - \alpha)^3$ の証明手順。

【証明の変形テクニック】

$(x - \beta)$ を $(x - \alpha) - (\beta - \alpha)$ と変形して被積分関数を展開する。

$$\begin{align*} (x - \alpha)(x - \beta) &= (x - \alpha)\left\{ (x - \alpha) - (\beta - \alpha) \right\} \\ &= (x - \alpha)^2 - (\beta - \alpha)(x - \alpha) \end{align*}$$

【定積分の実行】

$$\begin{align*} \int_{\alpha}^{\beta} (x - \alpha)(x - \beta) \, dx &= \int_{\alpha}^{\beta} \left\{ (x - \alpha)^2 - (\beta - \alpha)(x - \alpha) \right\} dx \\ &= \left[ \frac{1}{3}(x - \alpha)^3 - \frac{\beta - \alpha}{2}(x - \alpha)^2 \right]_{\alpha}^{\beta} \\ &= \left( \frac{1}{3}(\beta - \alpha)^3 - \frac{1}{2}(\beta - \alpha)^3 \right) - 0 \\ &= \left( \frac{2 - 3}{6} \right)(\beta - \alpha)^3 = \mathbf{-\frac{1}{6}(\beta - \alpha)^3} \quad \blacksquare \end{align*}$$
証明のポイント
展開してから普通に積分するよりも、$(x - \alpha)$ の一まりとして積分した方が、下端 $\alpha$ を代入した時に全項が $0$ になって計算が激変する。

演習問題［1］：微分係数と導関数

基本演習
【問題】
関数 $f(x) = 2x^3 - 3x^2 + 1$ について、導関数 $f'(x)$ および $x = 2$ における微分係数 $f'(2)$ の値を求めよ。
解答・解説
導関数：$f'(x) = 2 \cdot (3x^2) - 3 \cdot (2x) + 0 = \mathbf{6x^2 - 6x}$
$x = 2$ を代入して：$f'(2) = 6(2)^2 - 6(2) = 24 - 12 = \mathbf{12}$

演習問題［2］：接線の方程式

標準演習
【問題】
曲線 $y = x^2 - 4x + 3$ 上の点 $(3, 0)$ における接線の方程式を求めよ。
解答・解説
$y' = 2x - 4$ より、$x = 3$ における接線の傾き $m$ は：
$m = 2(3) - 4 = 2$
点 $(3, 0)$ を通り傾き $2$ の直線の方程式：
$y - 0 = 2(x - 3) \quad \Rightarrow \quad \mathbf{y = 2x - 6}$

演習問題［3］：関数の極値

標準演習
【問題】
関数 $f(x) = x^3 - 3x$ の極値を求めよ。
解答・解説
$f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$
$f'(x) = 0$ となるのは $x = -1, 1$
・$x = -1$ で極大値 $f(-1) = (-1)^3 - 3(-1) = \mathbf{2}$
・$x = 1$ で極小値 $f(1) = 1^3 - 3(1) = \mathbf{-2}$

演習問題［4］：定積分の計算

基本演習
【問題】
定積分 $\int_{1}^{3} (3x^2 - 4x + 1) \, dx$ を計算せよ。
解答・解説
$$\int_{1}^{3} (3x^2 - 4x + 1) \, dx = \left[ x^3 - 2x^2 + x \right]_{1}^{3}$$ $$= (27 - 18 + 3) - (1 - 2 + 1) = 12 - 0 = \mathbf{12}$$

演習問題［5］：面積の計算（1/6公式）

標準演習
【問題】
放物線 $y = x^2 - 2x$ と $x$ 軸で囲まれた部分の面積 $S$ を求めよ。
解答・解説
放物線と $x$ 軸の交点は $x(x-2) = 0 \Rightarrow x = 0, 2$
$1/6$ 公式を適用すると： $$S = \frac{|1|}{6}(2 - 0)^3 = \frac{8}{6} = \mathbf{\frac{4}{3}}$$

演習問題［6］：2曲線間の面積

応用演習
【問題】
放物線 $y = x^2$ と直線 $y = x + 2$ で囲まれた部分の面積 $S$ を求めよ。
解答・解説
交点の $x$ 座標：$x^2 = x + 2 \Rightarrow x^2 - x - 2 = 0 \Rightarrow (x-2)(x+1) = 0 \Rightarrow x = -1, 2$
区間 $[-1, 2]$ で $x + 2 \geqq x^2$ であるため、$1/6$ 公式より： $$S = \frac{1}{6} \{2 - (-1)\}^3 = \frac{1}{6} (3)^3 = \frac{27}{6} = \mathbf{\frac{9}{2}}$$
